# 短视频增长：投放、数据诊断与直播

只负责"放大"：把已经跑出转化能力的内容与直播间，用投放、数据诊断和直播运营做成可算账的规模。

## 定位与边界

- **只做放大，不做创作。** 投放、数据诊断、AB Test、直播运营归本 skill。
- **内容本身的问题归 `shortvideo-production`。** 脚本结构、口播表现力、分镜拍摄、剪辑、发布动作，本 skill 只给一句话结论加一句"交给 `shortvideo-production`"，不展开。
- **起号定位、赛道、账号搭建归 `shortvideo-launch`**；代运营报价与合同归 `shortvideo-agency`；团队分工与审片归 `shortvideo-team`。
- **投放放大的是已有转化能力，不能救内容。** 用户想靠投放解决"内容不行"，先把这句讲清，再决定要不要投。
- **本 skill 是套件里数值引用最密集的一个。** 正文所有具体数值都是**特定时点的第三方整理或公开素材经验值**；抖音规则与大盘持续变化，引用给用户时必须同时给出该数值的时点与"请以官方当前数据（如抖音电商罗盘）为准"，不得把任何数值当成当前平台规则。
- **视频号一律分轨。** 视频号的手册覆盖为零。凡涉及视频号，先写这句：
  `⚠️ 以下为抖音体系之外的通用实践，非本手册内容，需按视频号实际规则验证。`
  然后指向 `<skill-directory>/../knowledge/平台差异-抖音与视频号.md`。**禁止**把 DOU+ 的参数、时长、定向、金额拆分逻辑，以及抖音的 5 秒完播率权重与电商罗盘指标口径搬到视频号。

## 第一步：诊断

**不得脑补、不得用行业均值代替用户的真实数字。** 一次问完，缺哪项问哪项；用户答不上来的项，按"未提供"处理，不要替用户假设。

先问这 7 项：

| # | 要问的 | 为什么必须问 |
|---|---|---|
| 1 | **投放目标**：涨粉 / 引流到店 / 成交 / 收集线索 / 导流主页 | 决定 DOU+ 的"期望提升"选哪个，选错等于把钱花在不对的人身上 |
| 2 | **可用预算**：这次能花多少、这笔钱的盈亏线是多少 | 决定金额拆分份数与止损线 |
| 3 | **账号阶段**：新号无标签 / 已打标签 / 已有爆款 | 决定定向用智能推荐还是达人相似 |
| 4 | **已有数据**：这条视频的自然流量表现、最近 7 场直播平均场观、上月收入与成本 | 没有数据就没有诊断，见"失败与回退" |
| 5 | **是否做直播**：做/不做，几个人开播，有没有稳定福利货源 | 决定进直播工作流，还是只做投放与数据 |
| 6 | **能拿到哪些后台数据**：抖音电商罗盘、巨量百应、小店后台、第三方工具 | 决定诊断能做到多细 |
| 7 | **内容基础**：这条要投的视频，自然流量数据好不好 | 自然数据差就不该投，先回 `shortvideo-production` 改内容 |

拿到答案后按下面的顺序进工作流，不要跳步。

## 工作流

### 1. 判定本次属于哪一类，选一条主线

- 要花钱买曝光 → 走 **步骤 2 投放**。
- 给了后台数字、要"看数据然后告诉我改什么" → 走 **步骤 3 数据诊断**。
- 要做直播 → 走 **步骤 4 直播运营**。
- 三件事都要 → 按 投放 → 数据 → 直播 的顺序，因为投放的加投停投判据依赖数据底座。

### 2. 投放：设计一次可评估效果的 DOU+ 投放

读 `<skill-directory>/../knowledge/薛辉手册/16-第11章-DOU-投放-把钱花在刀刃上.md`（必读），需要关键数字速查时读 `<skill-directory>/../knowledge/薛辉手册/30-附录F-全流程速查表-可打印.md`。

**2.1 先过投放门槛。**
投放的本质是花钱买精准曝光，放大已有效果。
投之前自问："这条视频自然流量的数据好不好？"

- 自然数据好（完播率、互动率达标）→ 可以投，放大它。
- 自然数据差 → 不要投，先改内容。

【第三方转述】口径下的铁律：DOU+ 不能把烂内容变成好内容，只能让好内容被更多人看到。

**2.2 四个参数一次定完。**
期望提升（买什么）、时长（多久拿到播放）、定向（给谁看）、金额（花多少）。
期望提升必须与变现方式匹配：

- 本地生意（装修、餐饮）→ 位置点击量（需蓝 V 带位置）。
- 做电商、视频挂小黄车 → 商品购买。
- 做私域/咨询 → 线索量（企业号）或主页浏览量。

**选错类型 = 钱花在不对的人身上。**

**2.3 时长：默认 24 小时（或更长）。**
公开素材的经验值是"2 小时跟 24 小时，效果差距 50% 以上甚至更多"。该数值来自公开素材的投流经验值，非当前平台规则，请以官方当前数据为准。除非追热点需要立刻推流，不要选短时长：短时长曝光节奏过快，系统来不及精准匹配人群。

**2.4 金额拆分：拆开投，不要一次投完。**
公开素材的经验值是"一次性花 500 跟五次花 100，效果差距 10~20% 左右"。该数值同样来自公开素材经验值，非当前平台规则，请以官方当前数据为准。
执行方式：预算 500 元 → 分 5 次、每次 100 元、间隔投；每次投完看数据，不好就停，好就加。这是"用投放做测试"的思路，让每一批的结果指导下一批的决策。

**2.5 定向：智能推荐略好于手动定向。**
平台的算法比手动定向更了解用户；新号没有内容标签时，用**达人相似推荐**借同类达人的人群。支持批量投放，让系统自己选择最优质的作品去获取流量；**DOU+ 投到中途，隐藏视频可以强制停止投放**，这是止损技巧。

**2.6 用控制变量测试法分清"投错人"还是"内容差"。**
【本手册推断】这是"控制变量"思维在投放上的应用，与步骤 3 的 AB Test 是同一套逻辑，**不是薛辉原话**。
做法：用同样的金额，投两条内容质量明显不同的视频，然后看结果——

| 结果 | 结论 |
|---|---|
| 两条都差 | 内容问题 |
| 一好一差 | 内容问题（好的那条证明流量没问题） |
| 两条都不错但都不爆 | 可能是定向/人群问题 |

**2.7 算 ROI 并写死加投停投判据。**
`ROI = 产出（销售收入） / 投入（成本）`。投放前就定好止损标准：

| 判据 | 动作 |
|---|---|
| 单条投放 ROI < 1 | 立即停 |
| 连续 3 次投放 ROI 都不达标 | 停投，回去改内容和产品，**不是加预算** |
| ROI 趋势持续下降 | 人群接近饱和，换素材、换人群包或换品 |

【第三方转述】投放有天花板：初期投精准人群 ROI 高；中期精准人群被覆盖完，继续投会触达泛人群、ROI 下降。
最常见的亏钱方式是第一次投得好然后不断加预算，直到 ROI 跌破 1 才发现——**趋势比单次数据更重要**。

**2.8 "只要投赚钱就一直投"要带边界用。**
【第三方转述】公开素材的总原则是"把投资放在流量上""只要投赚钱就一直投"，逻辑链是 产品 → 流量 → 交付。

- **适用**：已跑通转化、ROI 稳定为正、人群未饱和。
- **边界**：必须同时看 ROI 趋势；持续下降时这条原则失效，转为 2.7 的止损动作，改内容、改人群包或改品。

**2.9 母婴私域路径的适用性分析。**
【本手册推断】公开素材里的母婴案例（抖音开账号 → 每天直播间分享母婴资料 → 拉群建群 → 2~3 个月微信加 1 万人 → 微商私域带货）**不是薛辉原话的适用性结论**，是推演出来的落地建议。

- 优势：人群精准度极高（微信里全是宝妈）。
- 劣势：慢（2~3 个月）。
- 适合：有产品、有耐心、有私域交付能力、不追求快速爆红的人。
- 与"投流冲爆款"是两种完全不同的打法。

引用这个案例前，先问用户有没有私域承接与交付能力；没有就在方案里明确劝退这条路径。

**2.10 产出投放决策表**（见"输出模板"①），写清四参数、拆分份数、止损线。

### 3. 数据诊断：从后台数字推出下一步动作

读 `<skill-directory>/../knowledge/薛辉手册/17-第12章-数据分析-看什么指标-算哪几个公式.md`（必读）。

**3.1 算流量：核心是 5 秒完播率。**
【第三方转述】5 秒决定用户"要不要继续看"，它是完播、点赞、评论、转化的前提——5 秒内划走，后面的数据无从谈起。
执行"5 秒优化法"：

1. 找出数据最好的一条，只看它的前 5 秒。
2. 问：第 1 秒出现了什么（画面/人/文字/声音）？第 3 秒说了什么？如果只保留这 5 秒，我会想继续看吗？
3. 拿数据最差的一条做同样的分析，对比差异。

结论通常很明显：好的那条前 5 秒有钩子（悬念/利益/冲突），差的那条前 5 秒在铺垫（打招呼、介绍背景）。
修改方向：把最有信息量的一句话提到最前面，不要"大家好，今天我想跟大家聊聊…"，直接说结论。
这项指标对应的三有原则是：有用处（这对我有用吗）、有兴趣（这有意思吗）、有共鸣（这说的是我吗）。

**3.2 情绪曲线。**
把文案抄下来，逐句标注它引发什么情绪（期待/好奇/恐惧/同情，另一版本表述为 实用/好奇/共鸣/兴奋/同情）。
【第三方转述】公开素材的表述是"一镜到底：枯燥，3 秒就需要一个情绪""分镜镜头比较多（画面也有情绪）"；**3 秒**这个节奏值来自公开素材，非当前平台规则，请以官方当前数据为准。
判断标准：连续 3 句以上标的是同一种情绪，或标不出情绪 → 这段太平，需要加冲突、加转折、加镜头变化。

**3.3 算收入：按路径选公式。**

| 路径 | 公式 | 适用与非注意点 |
|---|---|---|
| 店铺引流 | `抖音咨询量 × 进店邀约成功率 = 流量 × 咨询率` | 适用于高客单、决策重的生意（装修/房产/教育/医美），适用内容类型为故事类/过程类；**核心指标是咨询量，不是点赞量** |
| 电商卖货 | `收入 = 流量 × 转化率 × 平均客单价`；`利润 = 收入 − 成本（产品+人员+广告+样品）` | 所有优化的出发点 |

用公式找瓶颈，逐个变量问：

- 流量够不够？不够 → 做内容、投流。
- 转化率够不够？不够 → 优化话术、详情页、价格锚点。
- 客单价够不够？不够 → 做组合、做利润款搭配（见步骤 4.3、4.4）。

**【第三方转述】最常见的错误是只盯流量**：转化率从 1% 提到 2%，效果等同于流量翻倍，而提升转化率往往比涨粉容易。
算利润时必须把投放花费和样品成本算进成本项——投放花的钱是成本，样品寄出去也是成本；做活动冲销量前先算一遍利润。

**3.4 价值链优化六环节。**
链路：播放 → 购物车点击 → 跳转店铺 → 下单购买，加上购物车图片与商品评分/详情页的优化。
逐环节看流失：

| 环节 | 看什么数据 | 优化动作 |
|---|---|---|
| 播放 → 购物车点击 | 点击率 | 换购物车图片、优化视频结尾引导 |
| 购物车点击 → 跳转店铺 | 跳转率 | 确保挂的是抖音站内链接 |
| 跳转店铺 → 下单 | 转化率 | 优化详情页、产品图、评价、价格锚点 |

【第三方转述】公开素材明确提醒"一定要挂抖音链接。挂淘宝链接，当客户跳转链接时会损失客户"——用户从抖音跳到站外，中间流失非常大，能不跳就不跳。

**3.5 AB Test：这是本 skill 的核心方法，必须写清怎么设变量、怎么判定、记录什么。**
【第三方转述】公开素材明确要求"学会做 AB Test 测试（改变单一变量看结果变化）"。三个要求：① 只改一个变量——改了封面就不能同时改标题；② 同时/同期测试——不同时段测会被其他因素干扰；③ 样本足够——一条视频的差异可能是偶然，测试要重复。

可直接测的变量：

| 测试维度 | A 版本 | B 版本 |
|---|---|---|
| 开头 | 直接给结论 | 先提问 |
| 封面 | 真人出镜 | 文字为主 |
| 发布时段 | 中午 12 点 | 晚上 8 点 |
| 话题标签 | 行业词为主 | 人群词为主 |
| 视频时长 | 30 秒 | 60 秒 |
| 投放定向 | 智能推荐 | 达人相似 |

**判定规则**：两版在同一时间窗内跑，只比被测变量的那一项指标；差异要跨多次重复仍成立才写进结论；单次差异记为"待复测"，不要写成"已验证"。
【第三方转述】累计 20 条测试记录后，你就拥有了一份属于自己账号的规律——它比任何通用教程都准确，因为它在你自己的账号、类目、粉丝上验证过。这是从"新手"到"高手"的分水岭：新手在猜，高手在测。
**记录内容**：日期、测试变量、A 版本结果、B 版本结果、结论，一条一行（见"输出模板"③）。**记录的是"你自己的结果"，不要拿通用教程的数字当结论。**

**3.6 产出数据诊断表**（见"输出模板"②），每个指标后面必须跟"可能病因"和"下一步动作"，禁止只报数字不给动作。

### 4. 直播运营：把一场直播做成可复盘的方案

读 `<skill-directory>/../knowledge/薛辉手册/18-第13章-直播运营-流量池-选品排款与留人.md`（必读）。

**4.1 先定位流量池级别。** 【第三方转述】按平均场观分 S/A/B/C/D/E 六级（S 级 100W+、A 级 30W、B 级 8~10W、C 级 1~2W、D 级 1500 多人、E 级 167 人）。**该数值来自第三方整理的特定时点数据，抖音规则与大盘持续变化，请以抖音电商罗盘等官方当前数据为准。** 执行：看最近 7 场直播的平均场观，对应到级别。

| 级别 | 该级别该干的事 |
|---|---|
| E 级（167 人左右） | 不要想成交，先想办法把人留下来 |
| D 级（1500 人） | 重点优化话术和选品，把转化率提上去 |
| C 级（1~2W） | 已跑通模型，重点是放大（投流、增加场次） |
| B 级以上 | 团队作战，重点是供应链和排品 |

最常见的错误：**E 级的数据，用 B 级的话术和排品方案。级别不对，方法全错。**

**4.2 看流量来源结构，别拿旧占比做决策。**
【第三方转述】约 2022 年的第三方整理给出这组占比：

| 来源 | 占比 |
|---|---|
| 直播自然推荐 | 53.60%（含推荐 feed 49.49%、直播广场 3.86% 等） |
| 关注 tab | 32.11% |
| 短视频引流 | 4.51% |
| 其他 | 3.38% |
| 搜索 | 2.53% |
| 付费流量 | 2.17% |

**该数值来自约 2022 年的第三方整理，抖音规则与大盘持续变化，请以官方当前数据（如抖音电商罗盘）为准。**
这组数字的价值在于理解结构关系，不在于记住具体数字。

【本手册推断】结构关系解读（**不是薛辉原话**）：

- 自然推荐 + 关注 tab 合计约 85% → 直播间主要流量来自"平台推荐"和"老粉回流"。
- 付费流量仅约 2.17% → 直播间不是靠投流撑起来的（这与短视频带货不同）。
- 短视频引流仅约 4.51% → 占比小，但质量最高。

拿更高直播推荐要看五个指标：用户停留时长、点击成交转化率、粉丝率、互动率、千次观看成交率。
【第三方转述】短视频引流更精准（用户已通过视频了解你或产品后产生兴趣才进入）但生命周期短暂，需要有能产生爆款视频的能力。
让用户从视频进直播间，靠三种好奇：

| 好奇类型 | 什么时候用 | 公开素材的场景示例 |
|---|---|---|
| 对产品好奇 | 卖新品 | 想买钢化膜的人刷到视频，进直播间问价格 |
| 对人物好奇 | 有强人设 | 刷到美食博主视频引起食欲，进去发现他正在吃视频里那碗粉 |
| 对事件好奇 | 有活动/清仓 | 刷到"女装要破产"的视频，进去吃瓜发现 3000 人抢清仓 |

执行：直播前专门拍一条能引发这三种好奇之一的短视频，然后开播——不是随便发一条再开播。

**4.3 选品：先凑齐款型，再谈排款。** 【第三方转述】直播间商品分五类款型：

| 款型 | 作用 | 关键要求 |
|---|---|---|
| 福利款 | 钩子、留人专用，撬动整场自然流量 | 开播前 15 分钟用来拉互动、关注、停留；性价比高、应急性强、大众款、平台爆款；过完要用爆款衔接，不让在线掉到底 |
| 引流款 | 憋单（憋人数） | 例：1 块钱 6 瓶可乐 |
| 爆款 | 承接成交，有利润 | 颜值高、能让在线明显上涨、曝光点击 20% 以上、整场卖最好 |
| 利润款 | 单品利润最大，增加收益率与 UV 价值 | 与爆款搭配，让一个用户买多件；量不会特别多 |
| 形象款 | 形象展示、提升其他商品溢价 | 客单价较高、多用于展示、不是每个直播间都需要 |

**福利款和形象款可以没有，但爆款必须要有。** 没有爆款的直播间，只能靠福利款赔钱赚吆喝。（表中的开播前 15 分钟、曝光点击 20% 以上等数值来自公开素材与第三方整理，非当前平台规则，请以官方当前数据为准。）
【第三方转述】"用了福利款也拉不起流量"的两个原因是：用户、需求——即福利款没有匹配到真正的目标人群。

**4.4 排款：按团队规模选模式，不要跳级。** 【第三方转述】四种模式与其团队规模：

| 模式 | 定义 | 适合规模 |
|---|---|---|
| BBBB 单爆款循环 | 一直重复卖一个产品；要求它既是爆款又是福利款还是利润款，准备 3~5 套话术 | 1~2 人（新手主播最省心） |
| ABAB 福利爆款 | 福利款引流进直播间，用有利润的爆款转化；两款必须高度匹配、不能同质化太严重 | 1~2 人、有稳定福利货源 |
| ABCD 常规过款 | 多个不同目标的产品循环售卖，可临场穿插 | 2~4 人、成熟主播 + 完整直播脚本 |
| AAABCD 王炸福利 | A 福利款 + B 爆款 + C 利润款 + D 形象款 的组合 | 有品牌方支持/大促 |

【本手册推断】这四种模式的价值不只在于"怎么排品"，更在于它把直播复杂度与团队规模对应起来——这是推演出来的务实观察，**不是薛辉原话**。**1 个人的团队用 ABCD 模式几乎必然翻车**，因为记不住那么多卖点，节奏会乱。

**4.5 留人两个要素。**
【第三方转述】要素一：**直播间清晰度（布景）**。

- 灯光越足，画面越清晰；背景要有适当的景深；**千万不要大白墙**。
- 公开素材的预算建议是"假如预算是 5000 元，花 4000 元去买灯光"。
  该数值来自公开素材经验值，非当前平台规则，请以实际设备报价为准。
- 执行：先解决灯光，再考虑其他——画面清晰是留人的前提，用户看不清或画面暗会立刻划走。
- 大白墙的问题是：没有景深、没有信息、显得廉价。哪怕挂一幅画、放一排书、摆一盆绿植，都比一面白墙好。

【第三方转述】要素二：**直播间是否有内容**。三个检查点：

1. 是否搭建了有节奏的直播脚本。
2. 现在讲的产品或内容是否被用户喜爱。
3. 话术是否能留住人。

执行：开播前问自己"用户进来后的前 30 秒，我会说什么？"没有答案说明没准备脚本，这是留不住人的首要原因。

**4.6 话术：先归位心理账户，再给结构框架。**
【第三方转述】四大心理账户：

| 账户 | 典型商品 | 用户在意点 |
|---|---|---|
| 自我增值账户 | 钢琴课 | 想象空间、降低门槛、解决困境 |
| 维系情感账户 | 鲜花 | 行动成本、仪式感、价值感 |
| 规避风险账户 | 儿童椅 | 降低风险、风险背书、规避时效 |
| 日常开销账户 | 电蚊香 | 平民价格、使用频次、质量安全 |

拿用户的商品问一句：买它是为了"变更好（自我增值）/ 送人（维系情感）/ 防出事（规避风险）/ 过日子（日常开销）"？
归属不同，卖点完全不同：钢琴课不能讲"质量好"，要讲"零基础也能弹出一首歌"；鲜花不能讲"便宜"，要讲"今天买，明天就是母亲节"；儿童椅不能讲"好看"，要讲"通过了 XX 安全认证"；电蚊香不能讲"高端"，要讲"一盒用一夏天，全家都能用"。

**逐字话术是知识库的缺口**（`<skill-directory>/../knowledge/薛辉手册/27-附录C-信息缺口说明-本手册的边界.md` 第 6 条明确声明：只提供结构框架，逐字模板未收录）。**不要编造话术原文**，只给下面这个结构，让用户自己填实际话术：

| 账户 | 话术结构（照这个骨架自己填内容） |
|---|---|
| 自我增值 | 锁定目标人群 → 构建美好预期 → 解释如何用产品达成 → 罗列更多卖点 → 引导购买 |
| 维系情感 | 给出需求场景 → 场景带入、具象化描述 → 介绍产品特色 → 说活动 → 引导购买 |
| 规避风险 | 问题呈现 → 给出预期 → 问题出现的原因 → 如何用产品解决 → 罗列核心卖点 → 引导购买 |
| 日常开销 | 算明细账突显实惠 → 除便宜外品质好卖点 2~3 个 → 引导购买 → 再次强调高品质 → 强调销量 → 被动推荐理由 → 引导购买 |

【第三方转述】**不要四套都用，选一套练熟**——一套话术练 100 遍比四套各练 25 遍有效得多。其他话术类型：痛点话术、卖点话术、憋单话术、上架话术。

**4.7 选品红线与工具。** 【第三方转述·硬规则】商家体验分不能低于 4.7 分；达人口碑分低于 4.6 分不允许进行投放（相当于限流）。**这些分值与规则来自第三方整理，平台规则会变，请核实最新官方规则。** 选品不能只看佣金——一个低分商品可能让整个账号失去投放资格。直播工具：直播伴侣（开播）、抖音小店后台/商家工作台（店铺管理）、抖音电商罗盘（数据分析，核心）、巨量百应中控台（达人/机构管理）、第三方工具如蝉妈妈/抖查查（竞品与选品）。

**4.8 产出**：选品结构表 + 排款顺序（标出每款位置与作用）+ 话术结构框架 + 留人检查项。

## 失败与回退

| 情况 | 怎么处理 |

| 用户拿不出后台数据 | **先给取数清单**，不要凭感觉诊断：5 秒完播率、互动率、转化率、平均客单价、最近 7 场直播平均场观、上月收入与成本、每次投放的投入与产出。拿到数字再回来，不要把行业均值当用户数据 |
