# 单条视频制作：从脚本到发布

只处理**一条视频**的制作闭环：定脚本模型 → 写脚本 → 定表现力 → 写分镜 → 拍摄 → 剪辑 → 发布与评论区 → 判断"为什么没播放"。

不在职责内的一律一句话结论 + 指向：
- 账号定位、赛道、内容方向、选题库、起号排期 → `shortvideo-launch`。
- 投放（DOU+/微信豆）、数据复盘、AB Test、直播 → `shortvideo-growth`。
- 代运营报价合同 → `shortvideo-agency`；团队分工与审片 → `shortvideo-team`。

两条贯穿全程的硬口径：

1. **每条方法论结论都带可信度等级**：【公开表述】/【官方公开课】/【第三方转述】/【网络流传未核实】/【本手册推断】。说给用户听时用对应话术（"第三方整理的课程笔记里…（可能失真）"、"这是基于公开素材推演的落地建议，不是薛辉原话：…"）。禁止把推断说成手册事实，禁止编造薛辉原话。
2. **抖音是手册原生范围**。凡涉及**视频号**的任何结论，先顶一行 `⚠️ 以下为抖音体系之外的通用实践，非本手册内容`，再指向 `<skill-directory>/../knowledge/平台差异-抖音与视频号.md`，不得把抖音机制（DOU+ 定向、5 秒完播权重、电商罗盘指标）直接搬过去。

## 第一步：诊断

先补齐下面 6 项。缺哪项问哪项，**一次问完，不要挤牙膏、不要用行业均值代替**：

| # | 要问的 | 为什么要问 |
|---|---|---|
| 1 | 这条视频属于**五大型**中的哪一型？是要教知识、讲故事、说产品，还是晒过程/观点/段子？ | 决定选哪套脚本模型 |
| 2 | **谁出镜**、有没有对着镜头说过的经验、能不能接受真人口述？ | 决定表现力方案与难度等级 |
| 3 | **设备与场地**：手机够不够、有没有三脚架/麦克风/灯，能拍的真实场景是哪里？ | 决定景别运镜与是否需要低设备依赖的形式 |
| 4 | 发**哪个平台**：抖音还是视频号？ | 视频号触发平台分轨标注 |
| 5 | 有没有**对标参考**（同类爆款视频/账号链接）？ | 有参考就直接拆结构套模板，没有就先按模板起步 |
| 6 | 这条视频的**目标与选题**是什么？素材（经历、案例、产品、过程画面）现成吗？ | 脚本 = 模板 + 素材，没素材先补素材 |

类型不清、没有内容方向或选题时，告诉用户"这一步属于账号层面"，指向 `shortvideo-launch`（读 `<skill-directory>/../knowledge/薛辉手册/08-第3章-内容定位-五大型与三有原则.md` 定内容方向）。

## 工作流

按 1→9 顺序执行。每一步都写清读哪个文件、产出什么。

### 1. 定脚本模型

- 读 `<skill-directory>/../knowledge/薛辉手册/11-第6章-脚本体系-六类脚本模型与照读句式.md`。
- 先认类型：**六类脚本模型** = 晒过程、教知识、讲故事、说观点、尬段子、说产品【官方公开课】。资料中另有"四大脚本"的精简说法，手册采用六类，因为它覆盖变现环节。
- 再选模板：知识型走推荐型/解题型/盘点型/避坑型；热点型走伸张正义型/事件缘由型/未来影响型/历史交锋型；故事型走生活感悟型/个人成就型；产品型走场景难题型/知识带货型。
- **产出**：一句话选型结论 —— "类型 + 模板 + 为什么"。

### 2. 写脚本

- 再读 `<skill-directory>/../knowledge/薛辉手册/11-第6章-脚本体系-六类脚本模型与照读句式.md`（模板与句式全文都在这里），速查读 `<skill-directory>/../knowledge/薛辉手册/30-附录F-全流程速查表-可打印.md`。
- 讲清脚本的本质：**脚本 = 模板 + 素材**【第三方转述】。它是填空题，不是文学创作。
- 按模板顺序填三段：引发猎奇/待解决问题（开头）→ 推荐内容/解决办法（正文）→ 素材库/实操举例（结尾）。
- **照读句式可以直接给用户**，但必须标来源等级。手册把知识型四个模板的句式标为【第三方转述】（来自公开的第三方课程结构整理）。示例（完整清单读 `<skill-directory>/../knowledge/薛辉手册/11-第6章-脚本体系-六类脚本模型与照读句式.md`）：

| 模板 | 结构 | 照读句式示例（【第三方转述】） |
|---|---|---|
| 推荐型 | 引发猎奇 → 推荐内容 → 素材库 | "只有内行人才知道的…"、"推荐3个良心…" |
| 解题型 | 待解决问题 → 解决办法 → 实操举例 | "…的万能公式"、"三招让你…"、"核心就这X个点" |
| 盘点型 | 开篇点题 → 信息罗列 → 具体说明 | "盘点那些误解多年的…"、"盘点那些你一定不知道的…" |
| 避坑型 | 问题规避 → 错误示例 → 正确示例 | "千万不要…否则会…"、"记住这5点，不然被坑了你都不知道" |

- 句式只给 2–3 条示范，其余让用户照该文件的句式抄并改成自己行业的话，不要大段转抄原文。
- 脚本写**关键词版**，不写全文（附录F 第 6 步）。整句会诱使人照读，直接毁掉表现力。
- 没有素材/选题时，读 `<skill-directory>/../knowledge/薛辉手册/10-第5章-素材库与选题-八大爆款元素与选题四准则.md` 补素材库，或转 `shortvideo-launch`。
- **产出**：模板 ① 单条脚本表。

### 3. 定表现力方案

- 读 `<skill-directory>/../knowledge/薛辉手册/12-第7章-呈现与表现力-真人口述的三个关键点.md`。
- 三个关键点，全部按【第三方转述】交代，每条都带"优于"方向：

| 关键点 | 原则 | 落地动作 |
|---|---|---|
| 真诚 | 随意 > 刻意 | 戒提词器，把脚本改写成 3–5 个**关键词**贴在镜头旁，看着关键词说 |
| 情绪 | 高亢 > 沉静 | 想象对面坐着一个人而不是一个镜头；音量提到跟朋友聊天的水平。高亢 ≠ 喊，标准是"有起伏" |
| 场景 | 原生 > 塑造 | 在日常真正待的地方拍（厨房/工地/办公室），不要为了"专业"搭假背景 |

- 场景的**信任背书作用**（"医生在诊室说'我是医生'可信度更高"）属【本手册推断】，讲的时候必须说明"这是推演，不是薛辉原话"。
- 交代四个常见错误与修正（【第三方转述】）：气口有迟钝 → 分段录、用关键词；美白像女鬼 → 美颜参数调低；加速听不清 → 不加速，改为删冗余内容；眼神盯死人 → 把镜头当成一个人，视线可适当移开再回来。
- 用该文件（第 7 章）的四项及格线自检：中间无超过 1.5 秒空停顿、美颜没让五官变形、语速正常听得清、眼神自然。**任何一项不合格就重录**，这四项是及格线不是加分项。
- "找不到状态"时给**内心视像**方法（【第三方转述】概念）：录前想一个具体的人 → 想象他坐在对面疑惑地看着你 → 心里把第一句对他说一遍 → 开机接着说。四象限"决定流量的是内心视像而不是有没有交流对象"这一解读是【本手册推断】，必须标注。
- 需要提升画面可看性又撑不住真人口述时，用**呈现形式的维度升级**路径【第三方转述】：真人口述（门槛最低、最快产出，适合起号期）→ 真人口述+PPT（降低表现力压力、信息密度高）→ 视频+配音（画面丰富、不依赖出镜，需有素材积累）。升级一级前先确认上一级能稳定产出。
- **产出**：模板 ① 中的"口播与情绪提示"列 + 录制前动作清单。

### 4. 写分镜与关键镜头清单

- 读 `<skill-directory>/../knowledge/薛辉手册/13-第8章-分镜与拍摄-景别-构图与运镜.md`。
- 先讲定义：**分镜脚本 = 在不同的位置看一个连续动作**【第三方转述】；作用是丰富画面、提升张力、突出重点。
- 区分两个概念：**关键镜头**（连续动作的必要镜头，漏拍就只能重拍）、**生动镜头/情绪镜头**（特写或情绪镜头，负责可看性与点赞）。
- 开拍前写下 3–4 个关键镜头，每个一句话描述。这一步 5 分钟，省 2 小时重拍。
- 景别按用途选：远景（交代环境）、全景（人物与环境关系）、中景（肢体情绪、时间位置变化）、近景（面部情绪，说重点用）、特写（细节/产品）。
- 口播视频**至少两个景别**：开头结尾中景 → 讲重点切近景 → 提产品切特写。不要全程一个机位。
- 运镜七法：推、拉、横移、横摇、纵摇、跟随、环绕。新手只掌握两个即可 —— 推（开头，视线集中）+ 拉（结尾，收束感）。**手抖宁可不运镜**，晃动比固定画面更伤观感，用三脚架或靠稳。
- 需要转场或抒情时用**写意镜头**（思念拍月亮、失意拍秋天、迷茫拍人流、新的一天拍时间……共 9 条，读 `<skill-directory>/../knowledge/薛辉手册/13-第8章-分镜与拍摄-景别-构图与运镜.md` 取全）。建议平时攒空镜库：每个镜头 5 秒，横竖屏都行。
- **产出**：模板 ② 分镜表。

### 5. 拍摄执行

- 按分镜表顺序拍，**先拍关键镜头再补细节**，避免收工才发现缺镜头。
- 口播**分段录**（对应"气口有迟钝"的修正），一段一个意思，剪辑时再拼。
- 场景用原生场景（回到第 3 步）；治愈类内容的技术要点是画面清晰、饱和度高、收音清晰【第三方转述】。
- 发现现场条件不支持某个镜头时，当场降级景别或换成画面+配音，不要硬拍废素材。

### 6. 剪辑

- 读 `<skill-directory>/../knowledge/薛辉手册/14-第9章-剪辑基础-剪映六大核心功能.md`。
- 交代剪映**六大核心功能与作用**【第三方转述】：画中画/插图（叠加第二层画面，实现口播+PPT）、音效（强调重点、转场、制造情绪）、调色（提升饱和度、统一风格）、蒙版（局部显示/遮盖，做对比与转场）、关键帧（让元素随时间变化，静态图片缓慢放大）、动画（字幕图片进出场）。
- **缺口说明（必须说）**：手册只提供功能清单与作用说明，**不包含逐步操作教学**（读 `<skill-directory>/../knowledge/薛辉手册/27-附录C-信息缺口说明-本手册的边界.md`，缺口清单第 2 条）。不要自己编操作步骤、不要凭印象写菜单路径。用户要操作教学时，告诉他去剪映官方教程（剪映官方帮助中心 / 剪映官方账号），那里免费且比任何二手教程权威。
- 给"够用配置"，按需学而不是一次学完：先掌握剪掉废话（分割+删除）、加字幕（自动识别）、配乐；画面单调 → 关键帧；讲不清楚 → 画中画；情绪不够 → 音效；做治愈类 → 调色。
- 节奏提醒：一镜到底枯燥，"3 秒就需要一个情绪"【公开素材，经第三方转述整理】。剪辑就是替观众制造这个节奏。
- **产出**：成片 + 封面图。

### 7. 发布

- 读 `<skill-directory>/../knowledge/薛辉手册/15-第10章-发布与运营-话题-评论区与权重.md`。
- 基础动作：标题/文案里加 **#话题**（行业词 + 人群词，让分发更精准，**不要堆砌无关热门标签**）；需要时蹭平台热点话题；发布前过一遍社区规范/抖音规则中心。
- **权重认知（反直觉但必须讲）**："权重不影响涨粉，内容才影响。持续发布高质量内容，权重越来越高；持续发布低质量内容，权重越来越低。"【第三方转述】含义是：权重是结果不是原因，别把精力花在研究"是否被限流"上。
- 发布时间对齐目标人群活跃时段；需要挂车/挂链接就挂上（价值链与站内跳转的问题归 `shortvideo-growth`）。
- 视频号发布时，先打 `⚠️ 以下为抖音体系之外的通用实践，非本手册内容`，再指向 `<skill-directory>/../knowledge/平台差异-抖音与视频号.md`。
- **产出**：发布的视频 + 话题与标题。

### 8. 评论区运营

- 仍读 `<skill-directory>/../knowledge/薛辉手册/15-第10章-发布与运营-话题-评论区与权重.md`。七种方法（【第三方转述】）：

| 方法 | 做法 | 目的 |
|---|---|---|
| 总结视频内容 | 置顶一条总结性评论 | 帮没看完的人抓要点 |
| 引发再次评论 | 留一个开放性问题 | 提升评论量 |
| 引导进入主页 | "主页有XX" | 导流主页 |
| 立人设 | 用评论补充经历与态度 | 强化人物形象 |
| 植入种草 | 评论里自然提到产品 | 弱化广告感 |
| 神评论 | 自己发一条有梗的评论 | 引发二次传播 |
| 置顶评论 | 把最重要的评论置顶 | 控制第一印象 |

- 这七法的**底层逻辑**（把单向传播变成对话、让算法看到"有人在讨论"）是【本手册推断】，讲的时候带上说明。注：不同版本表述有"五法"与"七法"两种，手册按更完整的七项呈现。
- 固定动作：发完立刻自己写一条置顶评论（要点总结或补充信息）；前 1 小时内回复每条评论（尤其带问题的）；**不要删差评**（除非违规），差评是选题来源。
- 工具只作提示（蝉妈妈、巨量创意、轻抖、今日热榜、营销日历等，均为通用第三方工具，非薛辉独有）。提醒用户：工具解决信息获取，不解决内容质量。
- **产出**：评论区动作已执行（置顶评论 + 回复记录）。

### 9. 判断"这条为什么没播放"

- 读 `<skill-directory>/../knowledge/薛辉手册/17-第12章-数据分析-看什么指标-算哪几个公式.md`，指标口径以它为准；速查看 `<skill-directory>/../knowledge/薛辉手册/30-附录F-全流程速查表-可打印.md`。
- 先做三步排查，**在怀疑权重之前做完**：① 看 5 秒完播率（核心指标，低了就是内容问题，不是权重问题）；② 与自己上一条比（只有这一条差 → 选题问题）；③ 横向比同题材、同粉丝量级账号的同类内容。
- 结论通常是：不是被限流，是内容不够好。
- 用情绪曲线做简易自检：把文案抄下来逐句标情绪（期待/好奇/恐惧/同情/实用/共鸣/兴奋），连续 3 句以上同一种情绪或标不出 → 这段太平，加冲突、加转折、加镜头变化（这一"手动标注"在团队视角下会产品化为情绪曲线审片法，归 `shortvideo-team`）。
- 一旦问题变成"要不要投 DOU+""ROI 怎么算""要做 AB Test 吗""收入公式怎么套" → 给一句话结论，指向 `shortvideo-growth`，不要在这里展开。
- **产出**：模板 ④ 的自检结论 + 下一步动作。

## 输出模板

### 模板 ① 单条脚本表

| 段落 | 时长 | 内容（**关键词**，不写整句） | 照读句式（标来源等级） | 口播与情绪提示 |
|---|---|---|---|---|

## 失败与回退

| 症状 | 处理 |
|---|---|
| 表现力久久找不到状态、越录越崩 | 不要硬扛"地狱级难度"（真人口述+一镜到底+坐着+素背景），按难度坐标逐项降级：① 换真实场景 ② 插过程画面/产品特写 ③ 加道具与关键词字幕 ④ 改形式（真人口述 → 口播+PPT → 画面+配音）。核心思路：**表现力不够时用形式补**，能持续产出比单条完美更重要 |
| 没有拍摄条件 / 没人愿意出镜 | 给低设备依赖的形式：口播+PPT（降低表现力压力、信息密度高）或画面+配音（不依赖出镜）。景别只留中景+特写，运镜全固定 |

| 脚本写不出来、面对空白页 | 回到"模板+素材"：先抄第 6 章（`11-…`）的句式改成自己行业的话，再把手头素材往里填；素材确实没有 → 补素材库或转 `shortvideo-launch` |
| 热点类脚本涉及立场表达 | 提示风险：伸张正义型流量高但争议/违规风险最高；只陈述已公开事实，不臆测、不人身攻击、不传播未经证实的信息 |
| 用户要逐字讲稿/完整话术 | 说明手册只有结构框架与照读句式，逐字话术需自己填（缺口清单第 1 条） |
