## 第5章 素材库与选题：八大爆款元素与选题四准则

请注意，本章是全书最实操的一章： 八大爆款元素是可以直接套用的选题公式，不懂它你每天都会卡在"今天拍什么"。

本章学习目标　① 掌握八大爆款元素的定义与用法；② 学会用一份素材裂变出 8 个选题；③ 掌握选题四准则的判断方法；④ 建立自己的素材库。

预计学习时长　45 分钟　|　前置要求　第3、4章　|　学完你能　用一份素材产出 8 个不同角度的选题，并用四准则筛掉不合格的。

本章是全手册最实操的章节之一。选题决定了内容的80%——选题对了，脚本差一点也能火；选题错了，拍得再好也没用。

### 5.1 八大爆款元素

【公开表述】这是薛辉体系中最具代表性的工具。据其公开访谈整理，八大爆款元素为：

| 元素 | 定义 |
|---|---|
| 成本 | 少花钱、少费时、少费力，获得更大回报 |
| 人群 | 聚焦特定人群，尤其新手、首次体验者，让观众代入 |
| 最差 | 展示最低分、最难用、最糟糕，激发好奇 |
| 头牌 | 借助名人、名校、名企、顶级品牌的关注度 |
| 猎奇 | 呈现少见、意外、反常识的事情 |
| 反差 | 通过前后、身份或结果的对比，制造冲突感 |
| 荷尔蒙 | 围绕吸引力、恋爱、择偶和亲密关系 |
| 怀旧 | 唤起童年、过去的生活和共同记忆 |

核心用法（公开表述原文）：

"一份真实素材，换八种角度，找到最能引发兴趣或共鸣的切入点。"

这句话是本体系最值钱的一句。它意味着：你不需要天天找新素材，你需要的是把同一份素材从八个角度重切。

可直接执行的动作（八角度重切法）

1. 写下你今天真实发生的一件事（一份素材）。

2. 用八个元素逐一问："这件事能不能从成本/人群/最差/头牌/猎奇/反差/荷尔蒙/怀旧的角度讲？"

3. 八个角度里挑出你直觉上最想看的那个，先拍它。

4. 剩下7个记进选题库，以后没素材时拿出来用。

一份素材 → 八条视频。这就是"日更"能持续的根本原因，而不是靠每天硬想。

### 5.2 实操实例：美容院八选题（可直接套用的提问模板）

【公开表述】公开访谈整理中给出了一个完整演示——以美容院为例，用八个关键词各出一个选题。

原始提问方式（公开素材原文）：

"我是做美容院的，今天我想做一个自媒体的账号，然后给我出八个选题，这八个选题我给你八个关键词，成本、人群、最差、头牌、猎奇、反差、荷尔蒙和怀旧。那你围绕这八个词加上我的美容院给我出八个选题。"

【本手册改写——读者可直接使用的提问模板】：

我是一个【你的行业/身份】，主要服务【你的目标人群】，

客单价大约【金额】，我的优势是【你的差异化】。

请用八个爆款元素，各给我出3个选题，共24个：

1. 成本：怎么体现"少花钱/少费时/少费力，得到更大回报"？

2. 人群：怎么聚焦到特定人群（尤其是新手、第一次体验的人）？

3. 最差：怎么展示"最低分/最难用/最糟糕"来激发好奇？

4. 头牌：能借势哪些名人、名校、名企、顶级品牌？

5. 猎奇：我行业里有哪些少见/意外/反常识的事？

6. 反差：可以做哪些前后对比、身份对比、结果对比？

7. 荷尔蒙：怎么关联到吸引力、恋爱、择偶、亲密关系？

8. 怀旧：能唤起哪段童年、过去的生活或共同记忆？

每个选题写一行，标注它主要命中"有兴趣/有价值/有共鸣"中的哪一个。

【本手册推断·示例】以下是按上述模板为"社区美容院"生成的部分选题，用于演示元素的套用方式，非薛辉原案例：

| 元素 | 示例选题 | 命中三有 |
|---|---|---|
| 成本 | "在美容院做一次背，成本只有自己做面膜的1/3，但效果差多少？" | 有价值 |
| 人群 | "第一次进美容院的人，最怕被问的3个问题" | 有兴趣 |
| 最差 | "我体验了评分最低的那家美容院，结果…" | 有兴趣 |
| 头牌 | "雅诗兰黛实验室出来的配方师，怎么看几百块的护肤套餐" | 有价值 |
| 猎奇 | "美容院的'小气泡'到底吸出了什么？放大100倍给你看" | 有兴趣 |
| 反差 | "开店10年，最贵的一单和最便宜的一单，客户后来怎么样了" | 有共鸣 |
| 荷尔蒙 | "相亲前7天，皮肤急救流程（附时间表）" | 有价值 |
| 怀旧 | "20年前的美容院是怎么做脸的？我妈那代人的护肤法" | 有共鸣 |

注意观察：八条选题里，没有一条是在"卖套餐"。它们全都在提供价值或引发兴趣。这恰恰是产品型内容能起量的原因——先让人想看，再让人想买。

### 5.3 36个爆款词根

【第三方转述】除八大元素外，薛辉体系还将其拆解为36个爆款词根。公开来源给出了部分示例：

| 维度 | 词根示例 |
|---|---|
| 最差 | 最丑、最丢脸、最不保值、最难吃、评分最低、生意最差 |
| 成本 | 花小钱办大事、花大钱装大杯、最省时间的、最省钱的 |
| 怀旧 | 20年前、小时候、古代人怎么做的、那些消失的老东西 |

【第三方转述】用法说明原文：

"这些词根，就是你的选题素材库。当你卡壳时，只要拿「选题 + 词根」组合一下，基本就能出一个有流量的内容。"

可直接执行的动作（词根组合法）

1. 把你的行业名词写在中间：____（例：装修）

2. 从词根表里随机抽一个词根，套进去：

- 最省钱的 + 装修 = "装修最省钱的5个环节，很多人花反了"

- 评分最低 + 装修 = "我去了评分最低的装修公司，问了3个问题"

- 20年前 + 装修 = "20年前的装修和现在，最大的差别是什么"

3. 一次套5个词根，得到5个选题，挑最顺眼的先拍。

卡壳时不要干想，去套词根。 这就是"素材库"存在的意义——把创意变成组合动作。

【诚实标注】公开素材只给出了约13个词根的示例，"36个"这个总数来自第三方描述。完整36词根清单属于课程内容，本次未收录（见附录C）。

### 5.4 选题四准则

【第三方转述】薛辉体系提出选题的四条判断准则，每条都配有对比案例（这是最有价值的部分）：

#### 准则一：受众人群越广，选题越容易爆

| 对比 | 选题 | 人群范围 |
|---|---|---|
| ✅ | "怎样学好数学" | 所有想学好数学的人 |
| ❌ | "奥数应该怎么学" | 只想学好奥数的人 |

#### 准则二：内容利益性越强，选题越容易爆

| 对比 | 选题 | 利益强度 |
|---|---|---|
| ✅ | "月入2K的副业有哪些？" | 针对想副业赚钱的人，利益性强 |
| ❌ | "朋友答应帮忙，没回信要不要追问？" | 针对日常找人帮忙没反馈的人，利益性较弱 |

#### 准则三：解决成本越低，选题越容易爆

| 对比 | 选题 | 行动成本 |
|---|---|---|
| ❌ | "几个令人意想不到的赚钱小方法" | 抽象，行动成本不明确 |
| ✅ | "一个人，一台电脑，一天在家赚个几百块" | 在家用一台电脑就能赚钱，行动成本极低 |

#### 准则四：信息差越大，选题越容易爆

| 对比 | 选题 | 信息差 |
|---|---|---|
| ❌ | "广东的海，广东的冬天有多舒服呢？" | 针对想旅游的人，信息差小 |
| ✅ | "东山岛，推荐一个国内景美、人少、消费低的小众海岛" | 景美、人少、消费低，信息差大 |

【第三方转述】补充说明：

"冷知识容易火的原因，是因为知道的人少。"

更多对比案例（公开素材原文，用于体会"同主题不同写法"的差距）：

| 不够好 ❌ | 更好 ✅ |
|---|---|
| 适合新手妈妈做的3种宝宝辅食 | 教你10分钟就能做出一道简单的美食 |
| 1000元怎么做出一桌年夜饭 | 5块钱就能去米其林餐厅蹭一顿大餐 |

可直接执行的动作（选题四准则打分表）

每个选题按四项打分，每项1–5分：

| 选题 | 人群广度 | 利益强度 | 成本低 | 信息差 | 总分 |

|---|---|---|---|---|---|

| （写你的选题） | /5 | /5 | /5 | /5 | /20 |

总分16以上 → 直接拍。

12–15 → 改一改再拍（通常是"信息差"或"成本低"不够）。

12以下 → 放弃，换选题。不要在低分选题上浪费拍摄时间。

实战经验：四条准则里，"解决成本越低"最容易改——把抽象的表述具体化（"赚点外快" → "一天赚200，只要一部手机"），分数立刻上去。

### 5.5 素材库的建立

【第三方转述】这套体系里有一句很实在的话：

"赚钱的博主都有素材库。"

两类人的流程对比（公开素材原文）：

|  | 流程 |
|---|---|
| 普通人 | 有个灵感/想法 → 拍摄/剪辑 → 发布 |
| 专业人做账号 | 搭建素材库 → 确定选题 → 确定脚本 → 文案精修 → 选择呈现 → 拍摄剪辑 → 发布 → 数据复盘 |

核心要点：普通人和专业人的差距不在拍摄技术，在流程的前两步。普通人从"灵感"开始（灵感可遇不可求），专业人从"素材库"开始（素材库可以每天积累）。

#### 素材获取渠道（公开素材原文，完整清单）

| 类型 | 渠道 | 适配方向 |
|---|---|---|
| 搜索平台 | 百度、搜狗、必应、360 | 通用 |
| 热门内容平台 | 小红书（年轻人/美妆/服装/潮玩/游戏/健身） | 女性向、生活类 |
|  | 知乎（思维/人性类/创业/知识） | 知识型 |
|  | 新浪微博（段子类） | 段子、观点 |
|  | 喜马拉雅 | 故事、观点 |
| 热门图文平台 | 微信公众号（自己赛道）、简书、鲜知、今日头条 | 通用 |
| 垂直门户 | 装一网（装修）、马蜂窝（旅游）、下厨房App（美食）、懂车帝（汽车） | 行业专用 |
| 热点 | 今日热榜 | 热点型 |

#### 各类内容的素材库建设方向

| 内容方向 | 素材库来源 |
|---|---|
| 知识类 | 知乎、垂直门户、专业书籍 |
| 热点类 | 今日热榜、微博热搜、事件评论 |
| 故事类 | 个人经历、身边人、评论区 |
| 手艺类 | 自己拍摄的过程记录 |
| 产品类 | 产品资料、用户痛点、售后记录 |

可直接执行的动作（素材库搭建·今晚就能做）

新建一个文档/表格，建5个 sheet：知识 / 热点 / 故事 / 手艺 / 产品。

每天花 15分钟，把当天看到的有意思的东西按类丢进去，只记一行：来源 + 一句话概括 + 我觉得哪里有意思。

第3列是关键——它记录的是"你的判断"，而判断力才是选题能力的本质。

坚持2周，你会拥有100+条素材。此时"今天拍什么"就不再是问题。

注意：素材库不是收藏夹。收藏不等于素材——没有写下"我觉得哪里有意思"的收藏，等于没存。

#### 本章实操练习

①八角度裂变：拿一个你行业的真实素材，用八大爆款元素各出一个选题，凑满 8 个。

②四准则打分：给这 8 个选题按"受众人群广/利益性强/解决成本低/信息差大"逐条打分，淘汰最弱的 4 个。

③素材库开张：建立你的素材库表格，按知识/热点/故事/手艺/产品分栏，先各填 5 条。

#### 自测与小结

自测题

1. 八大爆款元素的核心用法是什么？

参考答案：一份真实素材，换八种角度，找到最能引发兴趣或共鸣的切入点。关键在"同一素材多角度"，而不是"找八个不同素材"。

2. 选题四准则中，哪一条最容易被新手忽略？

参考答案："解决成本越低越容易爆"。新手常选那些"需要观众付出很大行动成本"的选题（例如复杂的教程），结果完播率低。

3. 为什么"知道的人少"能让冷知识容易火？

参考答案：因为它天然满足"信息差越大越容易爆"这条准则——观众产生"原来如此"的获得感，愿意看完并转发。

本章小结

· 八大爆款元素：成本、人群、最差、头牌、猎奇、反差、荷尔蒙、怀旧

· 选题四准则：受众人群越广、利益性越强、解决成本越低、信息差越大，越容易爆

· 脚本不是靠灵感，是靠"把素材放进模板"——素材库是产出的前提

· 36 个爆款词根用于卡壳时快速组合出选题
