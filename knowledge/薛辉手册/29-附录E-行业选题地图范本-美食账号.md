## 附录E 行业选题地图范本（美食账号）

这是本手册中最具迁移价值的一节。

美食账号的三维选题地图来自公开素材，它演示了如何把一个行业拆解成几十个可执行的选题方向。

这个模型可以直接套用到任何行业。

### E.1 三维拆解法

| 维度 | 拆解逻辑 | 美食行业的示例 |
|---|---|---|
| 维度一：按形式 | 内容的呈现方式 | 农村美食 / 教程类（无真人出镜）/ 教程类（有人设出镜）/ 科普类 |
| 维度二：按主题 | 内容的具体内容 | 地方菜 / 家常菜 / 海鲜 / 烘焙 |
| 维度三：按人群 | 内容服务的对象 | 适合老人 / 小孩 / 一个人 / 小两口 / 减肥人 / 懒人 |

· 遇到爆款要翻拍

#### 怎么选品（公开素材原文）

· 销量榜：卖得好的一定好卖

· 视频热榜：火过的视频一定还容易火

#### 怎么拍（公开素材原文）

· 灯光很重要

· 角度也很重要

· "模仿对标账号是最快的方式，先把对标的镜头学会"

· 每个镜头找观众看最舒服的角度

· 拍出来的东西要让人看着想吃

· 色彩光泽够不够

· 声音是否清晰

### E.3 【可迁移】如何给你的行业做一张选题地图

▸ 落地建议（非官方SOP）——五步法

第1步：列出你的"形式"维度

问：我的内容可以用哪几种形式呈现？

（真人讲解 / 过程记录 / 对比测试 / 案例复盘 / 客户访谈 / 工厂实拍…）

第2步：列出你的"主题"维度

问：我的专业领域可以分成哪些子类？

（以装修为例：水电 / 瓦工 / 木工 / 油工 / 主材选购 / 预算控制 / 合同避坑…）

第3步：列出你的"人群"维度

问：我的客户可以按什么分类？

（以装修为例：首套房 / 二手房翻新 / 出租房简装 / 婚房 / 老人房 / 小户型 / 大平层…）

第4步：交叉组合

形式 × 主题 × 人群 = 选题数量

（6 × 7 × 7 =294个选题方向）

第5步：筛选

用第5章的选题四准则打分表筛选出前20个，作为首批选题。

这个五步法把"不知道拍什么"变成了一个机械的组合动作。

你会立刻发现：选题不是创意问题，是结构化拆解问题。
