## 第11章 DOU+投放：把钱花在刀刃上

请注意，本章的每一分钱都该有理由： 不知情的情况下投放 DOU+ 无法评估效果。

本章学习目标　① 理解投放的本质；② 掌握 DOU+ 的四个参数；③ 掌握时长与金额的拆分策略；④ 学会计算 ROI 并决定加投或停投。

预计学习时长　70 分钟　|　前置要求　第10章　|　学完你能　设计一次有明确目的、可评估效果的 DOU+ 投放。

### 11.1 投放的本质

【第三方转述】这套体系对投放有两句非常清醒的表述：

"本质意义就是花钱让别人强制能看到你，增加曝光。"

"投放是放大你赚的钱，没有其他秘密。"

第二句是关键。它意味着：投放不能救内容。

· 如果你的内容能赚钱 → 投放放大收入

· 如果你的内容不赚钱 → 投放只是放大亏损

可直接执行的动作（投放前的自问）

"这条视频自然流量的数据好不好？"

- 自然流量数据好（完播率、互动率达标）→ 可以投，放大它

- 自然流量数据差 → 不要投。先改内容。

一条铁律：DOU+ 不能把烂内容变成好内容，只能让好内容被更多人看到。

### 11.2 DOU+ 的四个参数

【第三方转述】投放需要设定四个参数：

| 参数 | 含义 | 说明 |
|---|---|---|
| 期望提升 | 花钱想买什么 | 见下方类型表 |
| 时长（小时） | 花钱想多久获得这些播放量 | 2小时 vs 24小时 |
| 定向 | 希望让谁收到 / 不让谁收到 | 智能推荐 vs 自定义定向 |
| 投放金额 | 这次花费多少钱 | 见拆分策略 |

期望提升的六种类型（公开素材原文）：

| 类型 | 适用条件 | 说明 |
|---|---|---|
| 点赞评论量 | 通用 | "花钱让一些爱点赞的人看到" |
| 粉丝量 | 想涨粉 | "花钱让一些爱点关注的人看到" |
| 主页浏览量 | 想导流主页 | 同上逻辑 |
| 位置点击量 | 蓝V带位置 | 本地商家引流 |
| 商品购买 | 视频挂小黄车 | 电商带货 |
| 线索量 | 企业号 | 收集销售线索 |

核心要点："期望提升"必须与你的变现方式匹配（回到第2章的变现方式选择）。

- 做本地生意（装修、餐饮）→ 投位置点击量

- 做电商 → 投商品购买

- 做私域/咨询 → 投线索量或主页浏览量

选错类型 = 钱花在不对的人身上。

### 11.3 时长策略：2小时 vs 24小时

【第三方转述】这套体系用"发传单"做类比（原文）：

1）一个人2小时发3000张传单，乱发

2）一个人24小时发3000张传单，能更精准

实际投流经验值（公开素材原文）：

"2小时跟24小时，效果差距50%以上甚至更多。"

可直接执行的动作：默认选24小时（或更长）。

除非有特殊理由（如追热点需要立刻推流），不要选短时长。

原因：短时长的曝光节奏过快，系统来不及精准匹配人群，等于把传单塞给了路人。

### 11.4 金额拆分策略

【第三方转述】同样的传单类比（原文）：

一次花500：3000张传单给一个人，效果不好

3000张传单给三个人，效果更好

实际投流经验值（公开素材原文）：

"一次性花500跟五次花100，效果差距10~20%左右。"

可直接执行的动作：拆分投放，不要一次性投完。

- 预算500元 → 分5次，每次100元，间隔投

- 每次投完看数据，数据不好就停，数据好就加

这实际上是一种"用投放做测试"的思路——分批投，让每一批的结果指导下一批的决策。

### 11.5 定向选择与技巧

【第三方转述】公开素材的定向相关结论：

| 结论 | 说明 |
|---|---|
| 智能推荐效果略好于定向 | 平台的算法比手动定向更了解用户 |
| 达人相似推荐适合标签未打上的 | 新号没有内容标签时，可借助同类达人的人群 |
| 批量投放，让系统自己选择最优质的作品去获取流量 | 同样金额测试多条视频 |
| Dou+投到中途，隐藏视频可以强制停止DOU+投放 | 止损技巧 |

其他方法（公开素材原文）：

1. 帮助信号快速过审

2. 强制人工审核看到我的作品

3. 测试到底是"流量不精准"还是"作品不优质"

4. 批量投放，让系统自己去选择最优质的作品去获取流量

5. Dou+ 投到中途，隐藏视频可以强制停止投放

第3条特别有价值：很多人投放效果差时，分不清是"投错了人"还是"内容不行"。

测试方法：用同样的金额，投两条内容质量明显不同的视频。

- 两条都差 → 内容问题

- 一条好一条差 → 内容问题（好的那条证明流量没问题）

- 两条都不错但都不爆 → 可能是定向/人群问题

【本手册推断】 这是"控制变量"思维在投放上的应用，与第12章的 AB Test 是同一套逻辑。

### 11.6 "只要投赚钱就一直投"

【第三方转述】公开素材给出的投放总原则：

"把投资放在流量上。" "只要投赚钱就一直投。"

逻辑链（公开素材原文）：

产品 —— 流量 —— 交付

"有粉丝之后就有了影响力。"

一个完整的投放案例（公开素材原文，母婴资料引流私域）：

抖音开账号

→ 每天直播间分享母婴资料、经验

→ 拉群、建群

→ 2~3个月微信加1万人

内容：妊娠期该怎么吃、怎么消除妊娠纹、免费发资料、

产后如何减肥、母婴备货清单、发表格

→ 微信全部是宝妈

→ 微商私域带货

这个案例值得细看：它不靠短视频爆款涨粉，而是靠直播间持续分享资料沉淀精准人群，再用私域变现。

【本手册推断】 这条路径的优势是人群精准度极高（全是宝妈），劣势是慢（2~3个月）。它适合有产品、有耐心、不追求快速爆红的人。这与"投流冲爆款"是两种完全不同的打法，读者应根据自己的资源选择。

### 11.7 投放的核心公式与风险提醒

【第三方转述】公开素材给出的两个关键公式：

ROI（投资回报率）= 产出（销售收入） / 投入（成本）

"当投到一定程度，人群的量是有限的。流量精准到再投，当有购买欲望的人全覆盖后，流量就开始泛（根据产品覆盖人群和领域来定）。"

这段话揭示了一个重要的投放天花板：

· 初期：投放到精准人群，ROI 高

· 中期：精准人群被覆盖完，继续投会触达泛人群，ROI 下降

· 此时：不要再加预算，应该换素材、换人群包、或换品

可直接执行的动作（投放止损线）

设定明确的止损标准，在投之前就定好：

1. 单条投放 ROI < 1（产出低于投入）→ 立即停

2. 连续 3次 投放 ROI 都不达标 → 停投，回去改内容和产品，而不是加预算

3. 记录每次投放的ROI变化趋势——如果持续下降，说明人群接近饱和

最常见的亏钱方式：第一次投得好，然后不断加预算，直到ROI跌破1才发现——此时已经亏了很多。趋势比单次数据更重要。

#### 本章实操练习

①设计一次投放：为一个具体目标（涨粉/测试完播/引流咨询）设计一次投放方案，写清四个参数。

②拆分对比：同一金额分别按"一次投"和"分五次投"执行，记录数据差异。

③算 ROI：制作一张投放记录表，包含投入、产出、ROI 三列，至少跑 3 条数据。

#### 自测与小结

自测题

1. 为什么"2 小时"和"24 小时"效果差距可达 50% 以上？

参考答案：本质是"发传单"的效率问题——24 小时能让系统更充分、更精准地找到目标人群，而 2 小时相当于把传单乱发。

2. DOU+ 的四个参数是什么？

参考答案：期望提升（买什么）、时长（多久获得播放）、定向（给谁看）、金额（花多少）。

3. 什么时候应该停止投放？

参考答案：当 ROI 持续低于你的盈亏线时。同时要注意：投到一定程度目标人群会饱和，流量开始变泛，此时加投效率下降。

本章小结

· 投放的本质是"花钱买精准曝光"，它放大的是你已有的效果，不能创造效果

· 时长要够长（优先 24 小时）、金额要拆分（多次小额优于一次大额）

· 定向选择：智能推荐略好于定向；标签未打上时用达人相似推荐

· 一切投放都要能算 ROI，否则不要投
