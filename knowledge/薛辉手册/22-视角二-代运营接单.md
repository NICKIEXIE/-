## 视角二：代运营接单

请注意，V2-2.1 是这部分最重要的一节： 它讲的是"不要承诺做不到的事"——这是代运营里最容易翻车的地方。

本部分学习目标　① 建立代运营的合规底线；② 掌握客户沟通与需求诊断方法；③ 掌握交付物、报价、验收的完整流程。

建议投入　接第一个客户前完整读一遍　|　前置要求　第1–14章

适用对象：帮别人做账号、接单赚钱的从业者。

本视角的核心不是"怎么做内容"（前面14章已讲），而是"怎么把这件事做成生意，且不出事"。

### V2-2.1 【最重要】先立规矩：不可兑现的承诺

这一节放在最前面，因为它是这个行业最大的坑。

【第三方转述·真实负面案例】公开素材记录了一条投诉（黑猫投诉，涉及《0基础短视频实操变现训练营》）：

"原来说好的包把账号做下来，有助理陪跑辅导，是课程质量太差了，完全没有效果…"

【本手册强调】这条投诉的核心问题不是课程质量，而是"包把账号做下来"这个承诺本身。

为什么这个承诺不可能兑现：

| 原因 | 说明 |
|---|---|
| ① 结果不由你单方面决定 | 账号起不起得来，取决于产品竞争力、供应链、价格、交付能力、老板的配合度、行业周期——这些都是你控制不了的 |
| ② 平台算法是变量 | 抖音的规则和流量结构持续变化（第13章的流量来源数据就是特定时点的） |
| ③ "做起来"没有定义 | 涨粉1万算做起来吗？有咨询没成交算吗？定义不清就必然扯皮 |
| ④ 它是法律意义上的"效果承诺" | 一旦写进合同或聊天记录，客户可以据此要求退款甚至索赔 |

#### ✅ 可以承诺的（过程性指标）

· 每周交付X条成片

· 每月完成X场选题会/复盘会

· 交付素材库、脚本、数据报告等具体产物

· 按约定时间节点完成发布

· 提供承诺数量的优化迭代

#### ❌ 不能承诺的（结果性指标）

· "包你把账号做起来"

· "保证涨粉XX万"

· "保证月销XX万"

· "保证上热门"

· "做不到全额退款"（这是最危险的表述）

▸ 落地建议（非官方SOP）——标准话术

当客户问"你能保证做起来吗"，这样回答：

> "我不能承诺结果，因为账号能不能起来，取决于您的产品、价格、交付和配合度，这些不是我单方能决定的。

> 我能承诺的是过程： 每月X条成片、X次复盘、完整的选题和脚本交付。

> 如果三个月后数据没有改善，我们可以复盘原因，也可以终止合作——但不会用'包做成'这种话跟您签合同，因为那对您不负责。"

这段话的威力：它把不可兑现的承诺换成了可衡量的交付，既降低了你的法律风险，也筛掉了只想"躺赢"的客户——后者是代运营最大的麻烦来源。

### V2-2.2 客户沟通问题清单

用途：第一次跟客户沟通时，按这张表问完，你就能做出方案。

【第三方转述】 公开素材中，官方产品教程提到一个思路："跟老板的谈资"——用生成的行业现状+痛点跟客户聊；并称"第一次跟客户聊的时候，把这些信息提供给他，其实账号搭建就已经完成了"、"聊天的过程当中，五分钟不到就把这些事情全聊完了"。

#### A. 客户基本情况（账号策划输入项）

| # | 问题 | 用途 |
|---|---|---|
| 1 | 您是谁？（姓名/称呼/身份） | 人设基础 |
| 2 | 您是哪里人？ | 地域标签（同城流量的关键） |
| 3 | 您的年龄？ | 人设与表达风格 |
| 4 | 您的性格？ | 决定出镜风格 |
| 5 | 您的行业是什么？做了多久？ | 内容方向 |
| 6 | 有什么荣誉/资质/证书？ | 背书素材（背景图、简介用） |
| 7 | 产品的客单价大约多少？ | 决定变现路径 |
| 8 | 有多少员工？ | 判断能配合的拍摄资源 |
| 9 | 您的商业目的是什么？（卖货/引流/招商/品牌） | 最关键的一问 |

#### B. 深度诊断问题（决定成功率）

| # | 问题 | 为什么问 |
|---|---|---|
| 10 | 您现在有没有做过抖音？做多久了？ | 判断是冷启动还是有基础 |
| 11 | 之前做过的话，具体数据是多少？（粉丝/播放/成交） | 判断真实起点 |
| 12 | 您觉得之前做得不好，原因是什么？ | 了解客户的认知偏差 |
| 13 | 您的客户是谁？他们最常问您什么问题？ | 选题金矿 |
| 14 | 您成交的最典型的一单是怎么来的？ | 找到可复制的内容钩子 |
| 15 | 您最想让谁看到您的视频？ | 明确目标人群 |
| 16 | 您最不希望谁看到？ | 避免误伤（如B端业务不想被同行看到报价） |
| 17 | 您的产品/服务和同行最大的区别是什么？ | 差异化定位 |
| 18 | 您能配合出镜吗？每周能配合几次、每次多久？ | 这是最常见的失败原因 |
| 19 | 您能提供哪些素材？（产品、场地、案例） | 判断内容产能 |
| 20 | 您的预算范围和期望周期？ | 报价基础 |
| 21 | 您希望多久看到什么结果？ | 预期管理——必问 |
| 22 | 如果三个月没效果，您会怎么想？ | 提前暴露分歧 |

▸ 落地建议（非官方SOP）

第18问（配合度）和第22问（预期）是筛选客户的关键。

- 如果客户说"我很忙，全交给你了"→ 这是高危信号。没有老板配合的账号，几乎做不起来（真人IP尤其如此）

- 如果客户的期望是"一个月爆"→ 提前讲清楚，否则三个月后必然纠纷

宁可前期丢掉这个单，也不要后期赔钱赔时间。 公开素材提到代运营签约周期通常三个月——这三个月的成本很高。

### V2-2.4 交付物清单

用途：明确"我交付什么"——这既是你的工作量凭证，也是验收依据。

| 阶段 | 交付物 | 形式 | 频率 |
|---|---|---|---|
| 启动期（第1周） | ① 账号定位方案 | 文档 | 一次性 |
|  | ② 账号搭建（头像/昵称/简介/背景图） | 落地执行 | 一次性 |
|  | ③ 对标账号分析表 | 表格 | 一次性 |
|  | ④ 内容规划（月度选题方向） | 文档 | 一次性 |
| 运营期（每月） | ⑤ 成片 | 视频 | 按合同约定条数 |
|  | ⑥ 选题库 | 表格 | 持续更新 |
|  | ⑦ 脚本 | 文档 | 每条一稿 |
|  | ⑧ 数据周报 | 表格 | 每周 |
|  | ⑨ 数据月报（含分析结论） | 文档 | 每月 |
| 复盘期 | ⑩ 月度复盘会 | 线上/线下会议 | 每月 |
|  | ⑪ 优化方案 | 文档 | 每月 |

▸ 落地建议（非官方SOP）

每一项交付物都要留痕（邮件/企微/飞书发送记录）。

原因：代运营纠纷中，最大的争议是"你到底做了什么"。有交付记录，就能证明工作量。

建议做法：建一个共享文件夹，按月归档，每周固定时间发一次交付确认。

### V2-2.5 报价逻辑与分层

【重要说明】 以下为 ▸ 落地建议（本手册推断），基于行业普遍做法整理，不是薛辉体系中的定价标准。薛辉体系的公开价格信息（训练营4980元、录播课5980元、营销课7980元等）属于其自身课程产品的定价，与代运营服务报价无关。详见附录A。

#### 报价的三个参照系

| 参照系 | 说明 |
|---|---|
| ① 成本法 | 你的人力成本 × 系数。算出你每月投入多少人天，按市场日薪计价，再乘1.5–3倍（覆盖沟通成本、试错成本、风险） |
| ② 价值法 | 客户的一个成交值多少钱？需要几个成交能覆盖你的服务费？这个方法能支撑更高报价 |
| ③ 市场法 | 同城/同行业的代运营报价区间 |

#### 分层报价模型（建议结构）

| 档位 | 服务内容 | 适合客户 | 特点 |
|---|---|---|---|
| 基础档 | 纯内容制作：每月约定期条数成片 + 选题 + 脚本 | 自己有团队做运营、只需内容产能 | 不承担结果，交付清晰 |
| 标准档 | 内容 + 账号运营 + 数据分析 + 月复盘 | 中小企业主，无人可用 | 主力产品 |
| 高阶档 | 标准档 + 直播代播/陪跑 + 投流代投 | 有产品、有预算、要快速起量 | 需团队支撑 |
| 顾问档 | 不出手，只出方案 + 定期指导 | 自己有执行团队 | 风险最低 |

▸ 落地建议（本手册推断）

建议从"基础档"或"顾问档"切入。

理由：这两档卖的是"工作量"和"专业知识"，不卖结果——风险可控、验收清晰。等到你有成功案例，再往上做标准档。

一个实用的定价技巧：报价时把费用拆成"基础服务费 + 效果激励"。基础部分保证你不亏，激励部分让客户觉得你们利益一致。但激励部分的触发条件必须是"可客观衡量的过程指标"（如曝光量、咨询量），不要用"成交额"（那是客户自己交付能力决定的）。

### V2-2.6 合同风险点清单

这一节请逐条核对。任何一条没写清楚，都可能在三个月后变成纠纷。

| # | 风险点 | 风险说明 | 写法建议 |
|---|---|---|---|
| 1 | 效果承诺 | "包做成"、"保证涨粉"→ 构成效果承诺，纠纷重灾区 | 明确写"服务方不承诺任何结果性指标" |
| 2 | 服务范围不清 | "运营抖音"太笼统，客户会无限加需求 | 逐条列出交付物（用2.4清单） |
| 3 | 内容条数不明 | 客户认为"每天都要发" | 写清每月X条，超出部分另计 |
| 4 | 修改次数无限 | 客户反复要求改，消耗你的产能 | 写清每条免费修改X次，超出另计 |
| 5 | 客户配合义务 | 客户不提供素材/不出镜，导致无法交付 | 写明客户的配合义务和时间要求，未履行则工期顺延 |
| 6 | 账号归属 | 合作结束账号归谁？ | 明确约定账号所有权归客户（这是行业惯例，也避免客户顾虑） |
| 7 | 素材版权 | 用了第三方素材引发侵权 | 约定素材版权责任划分 |
| 8 | 付款节奏 | 做完再付 → 你的现金流风险 | 预付 + 分期（如签约付50%，中途30%，尾款20%） |
| 9 | 保密与竞业 | 客户资料泄露 / 你同时服务竞品 | 双向保密条款 |
| 10 | 终止条款 | 中途不合作怎么办？ | 写清终止条件、通知期、已交付部分的结算方式 |
| 11 | 不可抗力与平台规则变化 | 平台改规则导致方案失效 | 写明平台规则重大变化时双方重新协商 |
| 12 | 目标定义 | "做好"没有标准 | 所有指标必须可量化、可查证 |

#### 2.6.1 特别提醒：关于"效果承诺"的正确表述

❌ 错误写法：

"乙方负责将甲方抖音账号运营至粉丝XX万、月成交XX单。"

✅ 正确写法：

"乙方负责按本合同约定完成内容制作与运营服务，交付物详见附件一。

乙方不承诺账号粉丝量、播放量、成交量等结果性指标。

双方同意以过程性指标的完成情况作为服务验收依据。"

▸ 落地建议（非官方SOP）

把"我们不承诺结果"这句话，主动说在客户开口之前。

听上去像是在推掉生意，但实际上：

- 它筛掉了不靠谱的客户（只想躺赢的那种）

- 它建立了专业形象（敢说边界的人通常是懂行的）

- 它保护了你的现金流（没有退款风险）

反过来说：越是拍胸脯"包做成"的同行，越是不可靠——因为他们在用承诺换签约，把风险留到三个月后。

### V2-2.7 验收标准

用途：让"验收"变成一个不需要争吵的动作。

建议的验收方式：过程验收 + 阶段评审

| 验收类型 | 验收内容 | 标准 | 频率 |
|---|---|---|---|
| 交付物验收 | 是否按清单交付了全部产物 | 有/无（客观） | 每周 |
| 数量验收 | 成片条数是否达标 | 数字比对（客观） | 每月 |
| 质量验收 | 成片是否符合脚本要求 | 按脚本比对（半客观） | 每月 |
| 阶段评审 | 数据是否有改善趋势 | 看趋势，不看绝对值 | 每季度 |

关键设计：把"能不能做起来"从验收标准里剔除，替换为"过程指标是否完成"。

这不是降低标准，而是让标准变得可执行——因为"做起来"没人能验收。

### V2-2.8 代运营的产能管理

【第三方转述】公开素材提到，官方产品支持多账号管理：最多登录5个账号，每个账号独立工作区；并可给客户开子账号。教程演示的场景是"沈阳铁西装修行业李哥"和"天津餐饮王姐"之间来回切换。

【第三方转述】教程中明确提到代运营签约周期通常是三个月。

▸ 落地建议（非官方SOP）

按"三个月一个周期"设计你的产能规划：

| 同时服务客户数 | 建议配置 | 说明 |

|---|---|---|

| 1–2个 | 个人可承担 | 内容制作 + 运营一人完成 |

| 3–5个 | 需要1名剪辑 | 一人负责选题脚本，剪辑外包 |

| 5个以上 | 需要团队 | 见视角三的岗位配置 |

不要超载接单。 代运营的口碑来自完得成，不是接得多。一个做砸的客户，会带走他圈子里的所有潜在客户。

### V2-2.9 从接单到标准化的路径

这是代运营从业者的成长路线。

| 阶段 | 特征 | 关键动作 |
|---|---|---|
| 第1阶段：接单赚钱 | 什么都接，靠时间换钱 | 积累案例，留下所有数据记录 |
| 第2阶段：筛选行业 | 只接自己熟的行业 | 把服务过的行业做成行业方案模板 |
| 第3阶段：产品化 | 把服务打包成标准产品 | 定档位、定交付物、定价格，不再一客一议 |
| 第4阶段：做工具/培训 | 从服务转向赋能 | 输出方法论（如本手册） |

▸ 落地建议（非官方SOP）

第2阶段是转折点。 当你只做一个行业时，你会发现：

- 选题可以复用（第3章的"行业选题地图"——美食账号的三维拆解就是范本，见附录E）

- 脚本可以模板化

- 报价可以更高（因为你是这个行业的专家）

公开素材中的美食账号案例，正是一个"行业选题地图"的完整范本：按视频形式、按内容主题、按受众人群三个维度，把一个行业拆成了几十个细分选题方向。这个模型可以直接套用到任何行业。

落地动作： ① 把 V2-2.1 的"不可兑现承诺"清单作为接单红线；② 用 V2-2.2 的 22 问做第一次客户沟通；③ 用 V2-2.3 诊断表形成书面需求确认；④ 合同签署前逐条核对 V2-2.6 风险点。
