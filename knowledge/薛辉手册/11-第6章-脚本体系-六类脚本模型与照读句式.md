## 第6章 脚本体系：六类脚本模型与照读句式

请注意，本章给的是可以直接照着念的句式： 六类脚本模型各有固定结构，初学阶段不需要原创，先套模板。

本章学习目标　① 理解"脚本=模板+素材"的本质；② 掌握六类脚本模型的结构；③ 背下至少 2 类脚本的照读句式；④ 学会按内容类型选择呈现方式。

预计学习时长　70 分钟（含大量句式模板）　|　前置要求　第5章　|　学完你能　针对任一选题，选对脚本类型并写出完整脚本。

本章提供可直接照抄的句式模板，是手册中最"拿来即用"的部分。

### 6.1 脚本的本质：模板 + 素材

【第三方转述】这套体系对脚本有一句核心表述：

"脚本不是靠天赋和灵感，是靠把素材放进模板里。"

这句话解决了新手最大的心理障碍。很多人不做视频的理由是"我不会写脚本"——但脚本不是文学创作，它是填空题。

可直接执行的动作：把本章的所有模板抄进你的素材库文档。写脚本时，不要面对空白页，打开模板往里填。

### 6.2 六类脚本模型

【官方公开课】根据多版本课程标题，六类脚本模型为：

| # | 脚本类型 | 课节标题（公开） |
|---|---|---|
| 1 | 晒过程 | "划重点！平台的超大流量体「晒过程」脚本落地教学" |
| 2 | 教知识 | "划重点！小白也能拍出流量的「教知识」脚本落地教学" |
| 3 | 讲故事 | "划重点！普通人塑造人设的通关密码「讲故事」脚本落地教学" |
| 4 | 说观点 | "短视频六类脚本模型(4)-说观点" |
| 5 | 尬段子 | "短视频六类脚本模型(5)-尬段子" |
| 6 | 说产品 | "划重点！只以变现为目标的『说产品』内容脚本落地教学" |

【第三方转述】注：不同版本课程中，"四大脚本"（聊观点 / 晒过程 / 教知识 / 讲故事）是常用的精简说法，六类为完整版。这又是一处公开资料的口径差异——本手册采用六类，因为它更完整，且能覆盖变现环节（说产品）。

### 6.3 知识型脚本模板（含照读句式全文）

以下照读句式来自公开的第三方课程结构整理，是该体系中最可直接复用的部分。

#### 模板1 · 推荐型

结构：

引发猎奇 → 推荐内容 → 素材库

照读句式（原文）：

· 只有内行人才知道的…

· 哪些…值得关注

· 推荐3个良心…

· 哪些冷门…值得购买

· 挑选…有哪些东西必须知道

完整范例（公开素材原文）：

【引发猎奇】只有内行人才知道的美妆博主：

· 养头发，跟着程姐走

· 去黑头，跟着大娘走

· 消痘痘，跟着圆圆走

· 学化妆，跟着勇仔走

【推荐内容】逐条说明为什么

为什么这个结构有效：它先制造"信息壁垒"（"只有内行人知道"），让你觉得不看就吃亏。然后给出具体名单——名单是收藏率最高的内容形态。

#### 模板2 · 解题型

结构：

待解决问题 → 解决办法 → 实操举例

照读句式（原文）：

· …的万能公式

· 如何判断 / 提高 / 写…

· 三招让你 / 教你…

· 快速…的小妙招

· 只需…就可以…

· 核心就这X个点，用这X个方法百试百灵，记住这个原则，XXXX

注意最后一句的结构："核心就这X个点"——用数字承诺确定性。这比"我来分享一下我的经验"有效得多，因为用户需要一个明确的边界（几点、几招、几步）。

#### 模板3 · 盘点型

结构：

开篇点题 → 信息罗列 → 具体说明

照读句式（原文）：

· 盘点哪些不可思议的…

· 盘点那些误解多年的…

· 盘点那些不可不知的…

· 盘点那些你一定不知道的…

· 盘点那些伤害不大，侮辱性极强的…

可直接执行的动作：盘点型的瓶颈是"凑不够数"。技巧是从你行业的常见误解入手——"盘点那些误解多年的装修常识"、"盘点那些你一定不知道的报税规则"。误解类盘点天然有反差（你以为 vs 其实），完播率高。

#### 模板4 · 避坑型

结构：

问题规避 → 错误示例 → 正确示例

照读句式（原文）：

· 千万不要…否则会…

· 做到这3点，可以避免…

· 怎样防止…

· 避免…有绝招 / 有妙招

· 记住这5点，不然被坑了你都不知道

完整范例（公开素材原文·买房避坑指南）：

【错误示例】

1）不买低层和顶层——低层挡光，顶层漏水

2）不买物业费便宜的小区——收费低注定服务差，后续居住麻烦不断

3）不买进深长的户型——采光不好，影响居住舒适度

【正确示例】

1）买中层或中上层

2）买物业服务管理好的小区

3）买南北通透开间大的户型

这个模板的威力在于"错误示例"这一栏。多数人讲知识直接给结论，而避坑型先描述错误做法——用户会立刻对号入座："我是不是也这么干了？"这个自我怀疑，就是完播的动力。

### 6.4 热点型脚本模板（四类结构）

| 子类型 | 结构 |
|---|---|
| 伸张正义型 | 开篇点题 → 复述事件/展示事件 → 为弱者发声/指责加害者 → 结尾表明观点 |
| 事件缘由型 | 一句话总结或点评事件 → 复述事件 → 罗列原因（按时间线/按因果排列） → 表明观点（总结+点评） |
| 未来影响型 | 开篇点题 → 复述事件/展示事件 → 列举事件带来的好处或后果 → 结尾点评/表明观点 |
| 历史交锋型 | 开篇简单描述或点评事件 → 复述事件 → 竞争经过（按事件线/关键时间节点） → 结尾点评 |

可直接执行的动作：四类里"事件缘由型"最适合新手——因为它的骨架最清晰（一个事件 + 罗列原因），不需要强观点输出。"伸张正义型"风险最高——涉及立场表达，容易引发争议或违规，需谨慎。

合规提醒：做热点内容时，只陈述已公开的事实，不要臆测、不要人身攻击、不要传播未经证实的信息。热点带来的流量高，但违规风险同样高。

### 6.5 故事型脚本模板

#### 生活感悟型

结构：

交代故事背景（时间+地点+人物+事件）

→ 矛盾冲突产生矛盾的经过

→ 故事发展注重描述细节

→ 事件转折点（万能台词："突然想到这件事，我就明白一个道理…"）

→ 得到感悟（找金句）

常见冲突类型（三类，公开素材原文）：

· 人与人之间：性格 / 观念 / 兴趣 / 肢体等的冲突

· 人与环境 / 事件 / 空间的冲突

· 人自己内心的冲突

#### 个人成就型

结构：

个人经历介绍（小人物 + 大成就）

→ 遇到的困难（困境呈现）

→ 事件重要转折

→ 逆袭经历成就展示

→ 总结感悟升华人物形象

可直接执行的动作：故事型的门槛是"我没什么故事可讲"。解决方案是不要讲大事，讲共性小事——回到第3章给出的10个故事选题方向（借钱、医院看病、上班累还是带娃累…）。这些事人人都经历过，共鸣来自共性，不来自戏剧性。

### 6.6 产品型脚本模板

模板A · 场景难题型：

生活中遇到的困扰

→ 困扰能否解决 / 解决的办法

→ 产品优点1、2、3…

模板B · 知识带货型：

直接说产品

→ 介绍产品 - 知识点1（注意事项）

→ 介绍产品 - 知识点2（吃法 / 佩戴方法 / 使用方法）

可直接执行的动作：产品型内容的最大陷阱是"像广告"。检验方法：把产品名遮住，这条视频还有价值吗？

如果有（用户学到了知识、知道了避坑方法）→ 好内容。

如果没有（全程在夸产品好）→ 重做成知识带货型。

### 6.7 脚本呈现方式的选择

【第三方转述】脚本方向与呈现方式需要匹配：

| 脚本方向 | 建议呈现方式 |
|---|---|
| 故事 | 真人口述、情景剧 |
| 知识 | 真人口述、口播+PPT |
| 过程 | 画面+配音 |
| 热点 | 真人口述 |
| 产品 | 真人口述、画面+配音 |

三种呈现方式的成本关系（公开素材原文）：

"用户越喜欢，行动成本越高。"

含义：情景剧用户最爱看，但拍摄成本最高；真人口述用户接受度一般，但成本最低。你需要根据自己（或团队）的产能做取舍。

| 呈现方式 | 用户喜爱度 | 制作成本 | 适合谁 |
|---|---|---|---|
| 真人口述 | 中 | 低 | 个人起号、0基础 |
| 画面+配音 | 中高 | 中 | 有素材可拍（手艺、产品、过程） |
| 情景剧 | 高 | 高 | 有团队、有演员 |

对个人起号者的建议：从"真人口述"开始。原因不是它效果好，而是它能让你持续产出。产量比单条质量更重要——尤其在前3个月（见视角一）。

#### 本章实操练习

①句式抄写：从知识型、热点型、故事型、产品型中选 2 类，把照读句式完整抄一遍并改成自己行业的话。

#### 自测与小结

自测题

1. 为什么说"脚本不是靠天赋和灵感"？

参考答案：因为爆款内容的共同结构是可以归纳的——把素材填进经过验证的模板，产出下限就被抬高了。灵感决定上限，模板决定下限，新手要先保下限。

2. 热点型脚本中"伸张正义型"的爆款规律是什么？

参考答案：受害者社会身份越弱，选题越容易爆。因为观众对弱者的代入和共情最强。

3. 产品类内容为什么强调"用教知识的方式卖产品"？

参考答案：直接说产品活动观众没有感觉；而从生活场景难题切入、用知识降低行动成本，观众才会觉得"有必要买"。

本章小结

· 六类脚本模型：晒过程、教知识、讲故事、说观点、尬段子、说产品

· 每类脚本都有固定结构与照读句式，初学先套用

· 热点型的四种结构与各自爆款规律是本手册最实用的部分之一

· 呈现方式的选择要与内容类型匹配，不是越复杂越好
