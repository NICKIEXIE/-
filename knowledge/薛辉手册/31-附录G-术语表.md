## 附录G 术语表

本表收录全书反复出现的专业术语，方便随时查阅。

| 术语 | 含义 |
|---|---|
| 完播率 | 看完视频的人数占播放人数的比例；5 秒完播率特指前 5 秒的留存比例 |
| 流量池 | 平台按数据表现逐级放大曝光的机制，等级越高获得的推荐量越大 |
| 账号权重 | 平台对账号内容质量的综合评估结果，不是可直接操作的指标 |
| 对标账号 | 与你定位相似、可参照学习的账号；需按行业/人设/呈现三维分别对标 |
| 商业定位 | 明确"靠什么赚钱"，即变现方式的选择 |
| 内容定位 | 明确"发什么内容"，即内容方向的选择 |
| 三有原则 | 判断内容质量的标尺：有兴趣、有价值、有共鸣 |
| 八大爆款元素 | 成本、人群、最差、头牌、猎奇、反差、荷尔蒙、怀旧 |
| 爆款词根 | 可组合进选题的关键词，如"最丑""花小钱办大事""20 年前" |
| 选题四准则 | 受众人群越广、利益性越强、解决成本越低、信息差越大，越容易爆 |
| 照读句式 | 可直接套用的句式模板，用于快速写出脚本 |
| 分镜脚本 | 把脚本拆解为多个镜头，标明景别、运镜与内容 |
| 关键镜头 | 一个连续动作的必要镜头，漏拍会导致素材不可用 |
| 写意镜头 | 用于过渡或抒情的空镜，如"思念拍月亮""失意拍秋天" |
| 内心视像 | 说话时在脑中构建真实的交流对象与场景 |
| 权重 | 见"账号权重" |
| 5 秒完播率 | 视频前 5 秒的留存比例，反映开头留人能力 |
| 情绪曲线 | 观众在观看过程中的情绪起伏；平缓处即流失点 |
| DOU+ | 抖音的内容加热投放工具，用于购买曝光 |
| ROI | 投资回报率 = 产出（销售收入）÷ 投入（成本） |
| AB Test | 每次只改变一个变量的对照测试 |
| 人设 | 账号对外呈现的人格形象，是建立粉丝偏好的核心资产 |
| 粉丝经济 | 先建立人物偏好、再持续变现的经营模式 |
| 心理账户 | 消费者对支出分类的心理机制：自我增值/维系情感/规避风险/日常开销 |
| 福利款 | 直播间用于留人与撬动自然流量的低门槛商品 |
| 爆款 | 能让在线人数明显上涨的商品；曝光点击率 20% 以上 |
| 利润款 | 单品利润最大、用于提升整体收益率的商品 |
| 形象款 | 用于展示、提升直播间价值层级的商品 |
| 憋单 | 通过延迟上架制造紧迫感、拉长用户停留的直播技巧 |
| 拆片 | 把一条爆款视频拆解为画面、文案、时长、景别等维度分析 |
| 拆片会 | 团队定期共同拆解爆款的固定机制 |
| 选题会 | 团队集中产出并筛选选题的固定机制 |
| SOP | 标准作业流程，把个人经验固化为可复制的步骤 |
| 口碑分 | 平台对带货达人的信誉评分，低于 4.6 分不允许投放 |
| 体验分 | 平台对商家的综合评分，影响达人口碑分与投放资格 |
