## 附录F 全流程速查表（可打印）

把这一页打印出来贴在工位。 它是本手册的浓缩版。

### F.1 内容生产流程（10步）

1. 商业定位  → 靠什么赚钱？能标准化吗？

2. 内容定位  → 五大型中选一类 + 三有原则中定一个

3. 账号搭建  → 头像/昵称/简介/背景图 + 对标三维度

4. 建素材库  → 5个分区，每天15分钟存5条

5. 选     题  → 八大元素 + 词根组合 → 四准则打分（≥16分）

6. 写脚本    → 套六类脚本模板（关键词版，不写全文）

7. 呈     现  → 真诚(随意) / 情绪(高亢) / 场景(原生) + 内心视像

8. 拍摄剪辑  → 关键镜头清单 → 景别切换 → 剪映

9. 发     布  → 话题 + 置顶评论 + 回复所有评论

10. 数据复盘 → 5秒完播率 + 情绪曲线 + AB Test

### F.2 每日动作（个人起号）

| 时段 | 动作 | 时长 |
|---|---|---|
| 早上 | 存素材 3–5条 | 10分钟 |
| 午休 | 写1条脚本 | 10分钟 |
| 晚上 | 拍摄+剪辑1条 | 20分钟 |
| 晚上 | 发布 + 置顶评论 + 回复 | 5分钟 |

### F.3 关键公式

| 公式 | 用途 |
|---|---|
| 收入 = 流量 × 转化率 × 平均客单价 | 电商卖货 |
| 利润 = 收入 − 成本（产品+人员+广告+样品） | 算真实收益 |
| 抖音咨询量 × 进店邀约成功率 = 流量 × 咨询率 | 店铺引流 |
| ROI = 产出（销售收入） / 投入（成本） | 投放评估 |
