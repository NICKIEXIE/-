## 第4章 账号搭建：四要素与对标三维度

请注意，本章完成的是"门面工程"： 头像、昵称、简介、背景图这四样，决定了刷到你的人要不要点关注。

本章学习目标　① 掌握火车节模型的账号策划流程；② 学会从行业、人设、呈现三个维度找对标；③ 完成账号搭建四要素的具体配置。

预计学习时长　40 分钟　|　前置要求　第2、3章　|　学完你能　交出一份可直接执行的账号搭建方案（头像、昵称、简介、背景图各一版）。

### 4.1 账号策划流程：火车节模型

【第三方转述】薛辉体系使用"火车节模型"描述账号策划的推进顺序：

商业定位（车厢1）→ 内容定位（车厢2）→ 拟定主题（车厢3）→ 找对标（车厢4）

公开素材中的完整示例：

| 环节 | 示例内容 |
|---|---|
| 商业定位 | 手机数码 |
| 内容定位 | 知识型 |
| 拟定主题 | 盘点历年火热机型 |
| 找对标 | （据此搜索同类账号） |

核心要点：这个顺序不能颠倒。先有"卖什么"，再有"怎么讲"，最后才是"讲什么题"和"看谁"。新手最常见的错误是从"找对标"开始——看别人做什么火就跟着做，结果做出来无法变现。

可直接执行的动作：把这四节写在自己的账号笔记第一页，每次要拍新内容前，从第一节往下读一遍，确认没有跳步。

### 4.2 对标账号的三个维度

【第三方转述】找对标账号有三个维度：

| 维度 | 看什么 | 作用 |
|---|---|---|
| 行业对标 | 同行业做得好的人 | 学内容选题（他们讲什么题能火） |
| 人设对标 | 人设气质与你相近的人 | 学表达方式（你怎么说话才自然） |
| 呈现对标 | 画面、剪辑、节奏风格 | 学表现形式（视觉上怎么呈现） |

公开素材中的减肥账号案例（演示三维度如何应用）：

| 对标角度 | 找到的类型 | 特点 |
|---|---|---|
| 段子型 | 志强 | 不容易复制，对文案内容要求高 |
| 知识型 | 奶斯要逆袭："那些你以为正确的减肥方法" | 可复制性强 |
| 手艺型 | （健身动作类） | 视觉冲击强 |

参考情绪呈现的案例账号（公开素材列出）：沈一只、碎嘴许美达、都靓读书、健身BOSS老胡、鹤老师说经济、孩百万。

可直接执行的动作（对标表）

建一个表格，行业对标找3个、人设对标找2个、呈现对标找2个，每个填四列：

| 账号名 | 对标维度 | 我学它什么（具体到某条视频） | 我不学它什么 |

最后一列最重要。"我不学什么"能防止你变成别人的复制品——抄袭型账号通常做不起来，因为用户会去看原版。

如何搜索对标账号（公开素材原文）：

1. 抖音搜索产品

2. 巨量算数（出现关键词再来抖音搜索）

3. 创作灵感

### 4.3 账号搭建四要素

【第三方转述】账号搭建包含四个要素：头像 / 昵称 / 简介 / 背景图。

#### 要素一：头像

核心原则（公开素材原文）：跟视频内容保持一致。

四种可选类型：

· 生活照 / 艺术照

· 职业照

· 卡通 / 萌宠

可直接执行的动作：翻开你的前5条视频，问："陌生人只看头像，能猜到我发什么内容吗？"猜不到 → 要么换头像，要么让内容更聚焦。

一个常见错误：真人账号用风景照或卡通头像。这会丢失"人"的信任感——而人设正是粉丝经济的核心（见第1章）。

#### 要素二：昵称

五种命名公式（公开素材原文，含真实账号范例）：

| 公式 | 结构 | 真实案例 |
|---|---|---|
| 名字 + 状态 | 你是谁 + 你在做什么 | 康姐要变美 / 程哥在考研 |
| 职业 + 姓名 | 你是干什么的 + 名字 | 花匠赵大发 |
| 姓名 + 地点 | 名字 + 地域 | 保罗在美国 / 王炸夫妻在日本 |
| 姓名 + 领域 | 名字 + 专业方向 | 超哥聊财经 / 鹤老师说经济 |
| 特质 + 姓名 | 特点 + 名字 | 疯狂小杨哥 / 碎嘴许美达 |

可直接执行的动作：从5个公式里选2个，各写一个昵称，念给一个不认识你的人听，问他"你觉得我是做什么的？"——答对=及格，答错=重写。

注意：昵称里出现领域词（如"财经"、"装修"、"美食"）是最稳妥的做法，因为它直接告诉算法和用户你是谁。纯网名（如"小清新"）需要靠内容慢慢教育用户，起号期吃亏。

#### 要素三：背景图

五种做法（公开素材原文）：

· 晒自拍

· 说价值

· 秀背书

· 说箴言

· 做引导

可直接执行的动作：背景图是免费的广告位，但90%的人浪费了。选一种做法，做成一张图：

- 秀背书：把你能拿出的资质、奖项、媒体报道截图拼上去

- 说价值：一行大字写清"关注我你能得到什么"

- 做引导：写清"点击主页→私信领取XX"

不要放纯风景图——它不传递任何信息。

#### 要素四：简介

四种做法（公开素材原文）：

· 说价值

· 说主题

· 做预告

· 秀背书

可直接执行的动作（简介四段式模板）

第1句：我是谁（身份+地域+年限）        ← 建立信任

第2句：我提供什么价值                   ← 说价值

第3句：我能帮你解决什么问题             ← 说主题

第4句：关注后可获得什么 / 何时更新      ← 做预告

写完后检查：一个陌生人读完这4句，知道要不要关注你吗？ 不确定 → 改。

### 4.4 一个人可以完成的视频类型

【第三方转述】公开素材列出三种适合单人操作的形式：

| 形式 | 案例账号 | 说明 |
|---|---|---|
| 纯口播型 | 金枪大叔、姜胡说 | 最省设备，最考验表现力 |
| 口播 + PPT | 薛辉小清新、有温度的女博士 | 降低表现力门槛，信息密度高 |
| 视频 + 配音 | — | 画面更多，配语音 |

核心要点：如果你是0基础且不擅长面对镜头，"口播+PPT"是性价比最高的起点——它把注意力从"你的脸"转移到"屏幕上的信息"，大幅降低表现力压力。薛辉本人的账号就用这个形式。

形式可以升级但不必一步到位：真人口述 → 真人口述+PPT → 视频+配音 是一条渐进的路径（见第7章）。

#### 本章实操练习

①三维对标表：用"行业对标/人设对标/呈现对标"三个维度各找 2 个账号，填成一张表。

②四要素落地：写出你的头像方案、3 个候选昵称、简介两版、背景图方案。

③火车节推演：用"商业定位→内容定位→拟定主题→找对标"走一遍，检查每一步是否连贯。

#### 自测与小结

自测题

1. 找对标账号为什么要分三个维度？

参考答案：因为一个账号的火可能来自行业红利、人设魅力或呈现技巧。只有拆开维度对齐，才知道你该学的是哪一部分，避免照搬表面形式。

2. 昵称的常见公式有哪几种？

参考答案：名字+状态、职业+姓名、姓名+地点、姓名+领域、特质+姓名。核心是让人一眼知道"你是谁、做什么、对他有什么用"。

3. 简介应该承担什么功能？

参考答案：说价值、说主题、做预告、秀背书——本质是回答"关注你能得到什么"，而不是自我介绍。

本章小结

· 火车节模型把定位变成一条可检查的链路，每一环都要能被验证

· 对标要拆成行业/人设/呈现三维，分别学习

· 账号四要素是"降低关注门槛"的工具，不是装饰
