## 第3章 内容定位：五大型与三有原则

请注意，本章直接决定你的内容有没有人看： "三有原则"是判断一条内容能不能火的快速标尺。

本章学习目标　① 掌握"有兴趣、有价值、有共鸣"三有原则；② 认识五大内容方向及各自细分类型；③ 理解公开资料中"五大型 vs 六种方向"的口径差异。

预计学习时长　60 分钟（3.2 节内容较长）　|　前置要求　第2章　|　学完你能　为自己选定 1–2 个主攻内容方向，并列举该方向的细分选题类型。

### 3.1 什么样的视频容易完播和点赞：三有原则

【第三方转述】薛辉体系提出内容被喜爱的三有原则：

有兴趣 / 有价值 / 有共鸣

【第三方转述】在数据分析章节中，同一原则被表述为"有用处 / 有兴趣 / 有共鸣"。

三有原则的实操拆解：

| 原则 | 用户心理 | 对应指标 | 怎么做 |
|---|---|---|---|
| 有兴趣 | "这跟我有关系" | 完播率、点击率 | 选题要对人（人群越聚焦越有效），标题要有悬念或反差 |
| 有价值 | "看完我能用上" | 收藏率、转发率 | 给出可执行的东西（清单、公式、步骤），不要只给观点 |
| 有共鸣 | "这说的就是我" | 评论率、点赞率 | 说出目标人群"想说但不敢说"的话（见第6章故事类脚本） |

核心要点：三者只需要命中一个就够火，命中两个就容易爆。 不要试图三者全占，那通常导致内容平庸。

实战判断法：做完一个选题，问自己"这条主要满足哪个？" 答不上来，说明选题模糊，重做。

### 3.2 五大型内容方向详解

【第三方转述】薛辉体系将内容方向分为五大类型：知识型 / 热点型 / 手艺型 / 产品型 / 故事型。

以下逐类拆解，包含细分类型、脚本结构、真实案例方向、以及每类的适配条件。素材来自公开课大纲与第三方整理的课程思维导图。

#### 类型一：知识型

细分类型（4种）：

| 子类型 | 结构 | 照读句式（公开素材原文） | 案例方向 |
|---|---|---|---|
| 推荐型 | 引发猎奇 → 推荐内容 → 素材库 | 只有内行人才知道的… / 哪些…值得关注 / 推荐3个良心… / 哪些冷门…值得购买 / 挑选…有哪些东西必须知道 | "只有内行人才知道的美妆博主" |
| 盘点型 | 开篇点题 → 信息罗列 → 具体说明 | 盘点哪些不可思议的… / 盘点那些误解多年的… / 盘点那些不可不知的… / 盘点那些你一定不知道的… / 盘点那些伤害不大，侮辱性极强的… | 最容易长肉的十种水果 |
| 解题型 | 待解决问题 → 解决办法 → 实操举例 | …的万能公式 / 如何判断·提高·写… / 三招让你·教你… / 快速…的小妙招 / 只需…就可以… / 核心就这X个点，用这X个方法百试百灵 | 长痘了怎么解决？ |
| 避坑型 | 问题规避 → 错误示例 → 正确示例 | 千万不要…否则会… / 做到这3点，可以避免… / 怎样防止… / 避免…有绝招·妙招 / 记住这5点，不然被坑了你都不知道 | 重庆旅行防坑 |

解题型的完整照读句式（公开素材原文，含范例）：

"核心就这 X 个点，用这 X 个方法百试百灵，记住这个原则，XXXX"

避坑型的结构范例（公开素材原文——买房避坑案例）：

错误示例：

1）不买低层和顶层——低层挡光，顶层漏水

2）不买物业费便宜的小区——收费低注定服务差，后续居住麻烦不断

3）不买进深长的户型——采光不好，影响居住舒适度

正确示例：

1）买中层或中上层

2）买物业服务管理好的小区

3）买南北通透开间大的户型

注意这个结构的精妙处：它不是"告诉你该怎么做"，而是先立一个"你以为是错的"靶子，再纠正。这制造了"我原来一直做错了？"的心理落差，是避坑型完播率高的根本原因。

知识型的适合人群：有专业积累、逻辑清晰、能面对镜头讲清楚的人。注意：公开素材中有一句很关键的表述——

"抖音教知识就像哄小宝宝开心（用户是小宝宝），怎么简单怎么来，怎么最快最简单地学会。"

【第三方转述】这句话揭示了知识型的核心约束：不要讲得深，要讲得快、讲得简单。专业越强的人越容易在这里翻车。

#### 类型二：热点型

细分类型（4种），每类有一个明确的爆款规律（这是本体系最"硬"的部分）：

| 子类型 | 爆款规律 | 脚本结构 | 案例 |
|---|---|---|---|
| 伸张正义型 | 受害者社会身份越弱，选题越容易爆 | 开篇点题 → 复述/展示事件 → 为弱者发声/指责加害者 → 结尾表明观点 | "我替小伙鸣不平"（拖车小伙身份低） |
| 事件缘由型 | 事件主角越惨，选题越容易爆 | 一句话总结或点评事件 → 复述事件 → 罗列原因（时间线/因果） → 表明观点 | "许家印掏家底救恒大"（变卖个人资产比较惨） |
| 未来影响型 | 概念越熟悉，选题越容易爆 | 开篇点题 → 复述事件 → 列举带来的好处或后果 → 结尾点评 | "拉闸限电是为了什么？"（用户对"拉闸限电"熟悉） |
| 历史交锋型 | 产品使用频率越高，选题越容易爆 | 开篇简单描述或点评 → 复述事件 → 竞争经过（事件线/关键节点） → 结尾点评 | "鹅厂音乐与网易云的恩怨史"（音乐软件使用频率高） |

四组对比案例（公开素材原文，这是理解热点选题的最佳材料）：

| 更容易爆 ✅ | 不容易爆 ❌ | 差异原因 |
|---|---|---|
| 我替小伙鸣不平（拖车小伙） | 欧莱雅该退差价吗（薇娅李佳琦） | 受害者社会身份弱 vs 强 |
| 许家印掏家底救恒大（变卖个人资产） | 华谊兄弟卖股还债 | 主角惨 vs 没那么惨 |
| 拉闸限电是为了什么 | 说一说"碳中和" | 概念熟悉 vs 不熟悉 |
| 鹅厂音乐 vs 网易云"恩怨史" | 统一 VS 康师傅方便面 | 使用频率高 vs 低 |

可直接执行的动作（热点选题4问）

拿到一个热点，依次问：

1. 这个事件里，谁是弱者？（有弱者 → 可做伸张正义型）

2. 主角够惨吗？（够惨 → 可做事件缘由型）

3. 涉及的概念用户熟悉吗？（熟悉 → 可做未来影响型）

4. 涉及的产品用户天天用吗？（高频 → 可做历史交锋型）

四个问题里命中一个，这个热点就值得做。命中两个以上，优先做命中最强的那个。

【第三方转述】热点素材库推荐：今日热榜。另有一个关键技巧——"利用热点事件评论里来自群众的发声"（评论区是现成的选题素材库）。

#### 类型三：手艺型

细分类型（2种）：

| 子类型 | 特征 | 爆款规律 | 案例 |
|---|---|---|---|
| 炫技类 | 展示技能过程 | 猎奇性越强越容易爆；视频越接地气越容易爆 | 赶海 |
| 治愈类 | 沉浸式、无强烈情绪 | 画面饱和度高、音效配乐清晰，越舒适越容易爆 | 烤面包、采耳沉浸式 |

两类手艺型的对比案例（公开素材原文）：

· 炫技类：赶海视频——"潮水还在涨"（激发好奇心弱）vs "哇，这个好大"（激发好奇心强）

· 治愈类：烤面包——画面调色、音效配乐好，让人感觉特别舒适（爆）vs 单纯展示面包做法、观看时没有特别情绪（不爆）

治愈型的核心三要素（公开素材原文）：画面清晰 + 饱和度高 + 收音清晰。

手艺类的脚本结构（与其他类型不同，手艺型是"镜头驱动"而非"文案驱动"）：

确定选题 → 关键镜头1 → 关键镜头2 → 关键镜头3 → 关键镜头4

（每个关键镜头不要太长）

手艺类的两种运营模式（公开素材原文，对代运营极有价值）：

| 模式 | 特征 | 案例 |
|---|---|---|
| 单选题手艺 | 每条视频同一呈现，选题单一，脚本都一样 | 给车贴膜撕膜、给马修蹄子、切肉 |
| 多选题手艺 | 每条视频选题不一样，但脚本一样 | 给车贴膜、设计纹身、LOGO设计、拍照、做饭、做手工、绘画 |

核心要点：手艺型是最适合"工业化生产"的类型——因为脚本固定，可以批量产出。这使它成为代运营和带团队的首选切入类型（见视角二、视角三）。

#### 类型四：产品型

细分类型（1种主要路径）：痛点切入型

两条爆款规律：

| 规律 | 反面案例 | 正面案例 |
|---|---|---|
| 从生活中的场景难题切入，难题发生频率越高，产品效果越好，选题越容易爆 | 直接说产品活动，用户没有感觉必须要买 | 从"避免马桶黄、用完厕所香香的"切入洁厕球 |
| 用教知识的方式把产品卖出去，知识越简单、实用性越强、行动成本越低，越容易爆 | 教"芝士焗生蚝"（做法复杂、门槛高、频率低、人群少） | 教"生蚝怎么吃"（频率高、门槛低、人群多） |

两种脚本模板（公开素材原文）：

模板A · 场景难题型：

生活中遇到的困扰

→ 困扰能否解决 / 解决的办法

→ 产品优点1、2、3…

模板B · 知识带货型：

直接说产品

→ 介绍产品-知识点1（注意事项）

→ 介绍产品-知识点2（吃法 / 佩戴方法 / 使用方法）

可直接执行的动作（产品型选题自检）

拿到一个产品，先别写卖点。回答：

1. 这个产品解决的麻烦，用户多久遇到一次？（每天/每周 → 好选题；每年 → 换角度）

2. 我能用"教知识"的方式讲它吗？ 如果能讲一个用户不知道的知识点，就比直接卖货强。

3. 我的选题，一个完全不了解产品的人会有兴趣看吗？ 没有 → 太"广告"了，重做。

#### 类型五：故事型

细分类型（2种）：

（1）生活感悟型

爆款规律：共性问题找得越准，情绪共鸣引发的越强，选题越容易爆。

对比案例（公开素材原文）：

| 案例 | 选题 | 点评 |
|---|---|---|
| 疯媳妇 ✅ | "孩子大了我帮你带" | 以宝妈身份讲述宝妈们的日常和面对家人态度时的内心活动，用吐槽方式替宝妈们发声，引起强烈共鸣 |
| 美琪 ❌ | "我和婆婆相处得很好" | 相处得好是婆婆的功劳，遇到好婆婆是个例、非共性问题，很难引起共鸣 |

脚本内容要点（公开素材原文）：

说出大众群体经历的共性经历；生活中常发生的难题，用第一视角说出他们想说而不敢说的话，为这个群体发声，过程中展现自己的生活智慧。

脚本结构：

交代故事背景（时间 + 地点 + 人物 + 事件）

→ 矛盾冲突产生矛盾的经过

→ 故事发展注重描述细节

→ 事件转折点 / 万能台词："突然想到这件事，我就明白一个道理…"

→ 得到感悟 / 找金句

常见冲突类型（公开素材原文，三类）：

1. 人与人之间：性格 / 观念 / 兴趣 / 肢体等的冲突

2. 人与环境、事件、空间的冲突

3. 人自己内心的冲突

（2）个人成就型

爆款规律：逆袭前后对比越强烈、逆袭后的生活越好，选题越容易爆。

脚本内容要点：普通人/弱势群体的逆袭故事——从普通或悲惨的现状到成功逆袭，分享成功经历、方法和心理过程，用亲身经历鼓励曾经跟自己相同的人。

脚本结构：

个人经历介绍（小人物 + 大成就）

→ 遇到的困难（困境呈现）

→ 事件重要转折

→ 逆袭经历成就展示

→ 总结感悟升华人物形象

故事类选题参考（公开素材原文，10个方向——这是现成的选题库）：

1. 老百姓的高光时刻

2. 我和爱人怎么在一起的

3. 成年人的委屈

4. 坏亲戚

5. 医院看病

6. 一分钱难倒英雄汉

7. 上班累还是带娃累

8. 来自陌生人的帮助

9. 借钱

10. 在XX城市一年要花多少钱

可直接执行的动作：把这10条抄下来，逐条问"我的目标人群里，有多少人经历过这个？"按人数从多到少排序，前3条就是你本周的故事类选题。

判断标准就一条：这个经历是共性的还是个人的？个人经历再感人也不容易爆。

### 3.3 【重要】口径说明：五大型 vs 六种内容方向

本节专门说明一个公开资料中的分歧，请读者注意。

分歧内容：

| 口径 | 内容 | 来源 |
|---|---|---|
| 5大类 | 知识型 / 热点型 / 手艺型 / 产品型 / 故事型 | 第三方整理的课程结构思维导图（2022） |
| 6种 | "抖音上能火的6种内容方向" | 多个版本课程的课节标题（官方公开课层面） |

本手册的处理：

本手册采用5大类口径作为主体结构，理由是其来源完整、细分类型与案例可查（每一类都有明确的子类型、脚本结构和对比案例）。

6种口径确实存在（在多个版本的课程标题中反复出现），但其具体分成哪6类，未能在公开资料中核实。

两种可能的原因（请读者自行判断）：

· 可能A：6类是把某一种细分类型提升为独立类别。例如把"知识型"下辖的推荐型（或盘点型/解题型/避坑型）单列出来。这个推测有一定依据——在公开课大纲中，这4个子类型有独立的脚本模板和照读句式，颗粒度上确实够"独立门户"。

· 可能B：6类中的某一类在导图版本里被合并了。

本手册不下结论。诚实呈现分歧本身就是这份文档的价值之一——市面上的资料往往各取一个版本、宣称唯一正确，读者无从判断。

5大类 → 细分类型 完整对应表（供两种口径的读者对照）：

| 5大类 | 细分类型 | 数量 |
|---|---|---|
| 知识型 | 推荐型 / 盘点型 / 解题型 / 避坑型 | 4 |
| 热点型 | 伸张正义型 / 事件缘由型 / 未来影响型 / 历史交锋型 | 4 |
| 手艺型 | 炫技类 / 治愈类 | 2 |
| 产品型 | 痛点切入型 | 1 |
| 故事型 | 生活感悟型 / 个人成就型 | 2 |
| 合计 |  | 13个细分类型 |

实用建议：不要纠结"到底5类还是6类"。真正有用的是这13个细分类型——每一个都有明确的爆款规律和脚本结构，直接拿去套选题就行。分类学上的争议，不影响你明天拍什么。

#### 本章实操练习

①三有自检：随手刷 10 条视频，逐条判断它满足了"有兴趣/有价值/有共鸣"中的哪几项，记录命中分布。

②方向选择：从五大型中选出 1–2 个适合你的主攻方向，写清"为什么是我"，并排除掉不适合的。

③细分清单：在你选的方向下，列出 8 个具体细分选题类型（参照 3.2 的案例）。

#### 自测与小结

自测题

1. 三有原则中，哪一项对新账号最重要？

参考答案：没有绝对答案，但对新账号而言"有价值"通常是最高效的切入点——因为它能带来完播与收藏，而这两项是算法判断内容质量的直接信号。注意：这是本手册的推断，不是薛辉原话。

2. 为什么同一素材可以做成不同类型的视频？

参考答案：因为内容方向是"切入角度"而非"素材本身"。同一件事，从知识角度讲是科普、从故事角度讲是经历、从热点角度讲是评论——角度决定受众与传播路径。

3. 公开资料中"五大型"与"六种内容方向"冲突，该怎么处理？

参考答案：不要强行合并。本手册采用来源完整的"五大型"口径，同时保留"六种方向"的说法并标注未核实。遇到冲突时，选择来源更完整、案例更可查的一方，并保留另一种说法供参考。

本章小结

· 三有原则（有兴趣、有价值、有共鸣）是判断内容质量的快速标尺

· 五大内容方向：知识型、热点型、手艺型、产品型、故事型

· 内容方向 ≠ 素材，而是"同一个素材的切入角度"

· 遇到公开资料口径冲突时，如实并列而非强行统一
