第 3 章　内容篇：一天八条从哪来

3.1　内容总纲：七大类，覆盖从陌生到成交的全过程

建材客户的决策要经历很长一段路：先不知道你，再开始了解材料，再比较价格，再验证你是不是靠谱，最后才联系你。每个阶段需要的内容是不同的。 很多账号做了半年没线索，原因就是七类内容里只做了一类。

| 序号 | 内容类别 | 解决客户哪个心理阶段 | B/C | 占比 |
|---|---|---|---|---|
| ① | 信任与实力（工厂、仓库、团队、资质、案例） | “这家是不是正经公司” | B为主 | 20% |
| ② | 产品与工艺（拆解、对比、参数、真假鉴别） | “东西好不好” | B+C | 20% |
| ③ | 避坑与知识（怎么选、坑在哪、行业黑话） | “我不懂，需要有人教我” | C为主 | 20% |
| ④ | 报价与成本（价格构成、多少一平、为什么有差价） | “多少钱，会不会被坑” | C为主 | 15% |
| ⑤ | 案例与交付（工地过程、完工效果、客户反馈） | “别人用了吗，效果怎样” | B+C | 15% |
| ⑥ | 政策与招商（代理政策、区域保护、合作条件） | “我能不能跟你合作赚钱” | B为主 | 5% |
| ⑦ | 老板人设（创业故事、行业观点、日常、价值观） | “我信不信你这个人” | B+C | 5% |

| ★ 七类内容的排期原则 建号前 30 天：①②③ 为主（先建立专业形象与信任基础），不要一上来就发招商政策。 30 天之后：按上表比例混排，保证每天都有一类“硬内容”（②或④）和一类“软内容”（⑤或⑦）。 ⑥政策类内容要少而精：发太多会把账号标签带偏成“招商号”，推荐页会开始推给同行而不是客户。 |
|---|

3.2　选题从哪里来：四个来源，永不缺题

3.2.1　来源一：客户的真实提问（最高价值）

这是建材账号最该用、却最少人用好的来源。你每天在店里、电话里、微信里回答的问题，每一条都是一个现成的选题。

· 在门店柜台放一个本子或建一个微信群，每次客户提问就记一句

· 每周汇总一次，把重复出现的 3 个问题做成 3 条视频

· 同一个问题可以反复拍：换个客户案例、换个说法、换个人讲，就是新的一条

· 这类视频的特点是播放量不高但询盘率高，因为看的人正是有同样问题的人

3.2.2　来源二：搜索词与下拉框

建材是搜索型需求（见第1.2.2节）。打开抖音搜索框，输入你的城市 + 品类，看下拉提示和“大家还在搜”，那就是最真实的客户需求清单。

· 搜「你的城市 + 品类」（如“杭州断桥铝门窗”）→ 记录下拉词

· 搜「品类 + 多少钱」「品类 + 怎么选」「品类 + 避坑」

· 看搜索结果里播放量最高的同行视频，抄它的选题，不抄它的内容

· 把这些词存进选题库表格（附录A），标注搜索热度

3.2.3　来源三：工地与门店现场

这是建材行业独有的选题富矿。每一次上门、每一次施工、每一次进货，都是素材。

| 现场场景 | 可裂变出的选题示例 |
|---|---|
| 上门量尺 | “今天去量尺，发现房东这个窗户做了个致命错误”／“量尺时我一定会问客户这3个问题” |
| 安装施工 | “师傅安装时这一刀如果不切，三年后一定漏水”／“这个位置我们多花20分钟，为了什么” |
| 进货卸货 | “今天到了30吨货，教你怎么辨真假”／“为什么同一个型号有两个价，看这批货就知道了” |
| 客户验收 | “客户验收时最在意的3个细节”／“这个客户以前踩过坑，看看我们怎么补救” |
| 旧房改造 | “这套20年老房的窗户拆开，里面全烂了”／“翻新最不值得省钱的三个地方” |
| 门店接待 | “今天一个客户拿别家报价来问，我给他逐条拆开”／“这几种客户我一般不接，为什么” |

3.2.4　来源四：行业问题与同行

· 同行踩过的坑：同城同行被投诉、被曝光的案例（只讲事不点名，避免法律风险）

· 行业黑话解读：把专业术语翻译成人话（“什么是系统窗”“E0级和ENF级差在哪”）

· 季节性节点：3~5月装修旺季、9~11月第二波、雨季防水、冬季保温——按季节提前备内容

· 政策与标准：新国标、检测标准变化，这类内容B端特别爱看

3.3　选题验证：四条准则，砍掉一半废题

有了选题不等于能拍。用下面四条过一遍，不满足的不要浪费产能。

| 准则 | 问自己 | 不满足时的表现 |
|---|---|---|
| 有人关心 | 这个问题客户真的问过吗？还是我自己觉得重要？ | 播放量 200 以下，且评论区无人讨论 |
| 有差异 | 同行会怎么说？我这个说法有没有不同？ | 内容和同行一模一样，没有点开的理由 |
| 能落地 | 我现在能拍出来吗？（有实物/有工地/有案例） | 需要借场地、等货、找模特——成本过高 |
| 有钩子 | 前 3 秒能不能让人停下来？ | 开头是“大家好，我是XX”这类无效开场 |

来源： “选题四准则”的框架口径参考 shortvideo-suite 知识库《薛辉手册·第5章 素材库与选题》的【公开表述】内容，本表按其框架做建材行业改写，示例为 ▸ 本手册推断。

3.4　八大爆款元素：给标题和开场加速

同一件事换个说法，效果差十倍。下面八个元素，是让标题和开场产生点击欲的杠杆。每条视频至少用两个。

| 元素 | 作用机制 | 建材行业示例 |
|---|---|---|
| 利益 | 让人看到能得到什么 | “装窗户省下 8000 块，就靠这三个决定” |
| 好奇 | 制造信息缺口 | “为什么师傅量完尺，会要求我把旧窗户留着？” |
| 对比 | 制造落差，最有冲击力 | “左边 380 一平，右边 980 一平，切开看差在哪” |
| 数字 | 具体化，增加可信度 | “20 年老房翻新，这 5 个地方千万别省钱” |
| 反常识 | 打破预期，逼人停留 | “越贵的瓷砖不一定越好，这 3 种情况买便宜的更对” |
| 恐惧/避坑 | 损失厌恶 | “这个做法，三年后一定漏水，现在改还来得及” |
| 身份认同 | 让特定人群觉得“说的是我” | “自己找人装修的，这条一定要看” |
| 时效/稀缺 | 制造紧迫感 | “雨季前这一周，是补漏最后的窗口期” |

来源： “八大爆款元素”的框架口径参考 shortvideo-suite 知识库《薛辉手册·第5章》【公开表述】；本表所有建材示例均为 ▸ 本手册推断·示例，非原作者内容。

| ★ 使用方式 先选模板 → 把方括号里的内容换成你的实际情况 → 完整念一遍看是否顺口 → 上提词器或写在纸上。 时长控制：知识类 40~70 秒，产品类 30~50 秒，案例类 45~90 秒，招商类 60~90 秒。 不要追求一条爆款。 建材账号的收益来自“稳定输出 × 精准选题”，不是单条爆发。 |

3.6　套拍矩阵法：一次拍摄，八条发布

这一节是解决你核心痛点的关键。单人日产 8 条，靠的不是手速，是结构。

3.6.1　核心思路：把“拍摄”和“发布”解耦

大部分人的做法是：想一个选题 → 拍一条 → 剪一条 → 发一条。这个链条的瓶颈在拍摄，因为拍摄要布景、要出镜、要找东西。

套拍法的做法是：一次布景拍多条，一次拍摄切多版。 把“拍摄次数”压到最低，把“内容版本数”放到最大。

|  | 传统做法 | 套拍矩阵法 |
|---|---|---|
| 每周拍摄次数 | 6~7 次（一条一拍） | 2 次（一次拍一批） |
| 单次拍摄产出 | 1 条 | 12~16 条素材片段 |
| 剪辑方式 | 一条一剪 | 按模板批量套剪 |
| 每周发布量 | 6~7 条 | 56 条（含两平台版本） |
| 瓶颈 | 拍摄（要出镜、要布景） | 剪辑（可模板化、可外包） |

3.6.2　一次拍摄的完整拆解（以“去工地”为例）

假设你今天要去一个工地做安装或验收。这一次出行，应该带回下面这些素材：

| 拍摄位置 | 拍什么 | 能切成几条内容 | 对应类别 |
|---|---|---|---|
| 车上/路上 | 口播：“今天去哪、去干什么、为什么值得拍” | 1 条（老板人设/预告） | ⑦ |
| 到达现场全景 | 工地全景、门牌、小区名 | 1 条（同城地标，强化地域标签） | ⑤ |
| 问题部位特写 | 发现的问题、旧料拆开的样子 | 2 条（避坑 + 拆解） | ③② |
| 施工动作 | 切割、打胶、安装、调平的关键动作 | 3 条（工艺细节 + 数字 + 反常识） | ② |
| 与客户对话 | 客户提问 + 你的回答（征得同意） | 2 条（真实问答，信任度极高） | ⑤⑦ |
| 成品效果 | 完工前后对比、细节收口 | 1 条（对比元素，效果最直观） | ⑤ |
| 收工口播 | “今天这个活说明了什么”+ 行动指令 | 1 条（观点升华） | ⑦ |
| 花絮/工具 | 工具展示、师傅手艺、轻松片段 | 1~2 条（人设立体化） | ⑦ |

| ✓ 关键动作：先拍够，再想怎么发 拍摄时不要想着“这条要发到哪个号”。 先按上表把素材拍满，回来再按第4章的配方切版本。 素材一定要拍“干净底”：同一句口播，多录两遍不同说法；同一个动作，多拍两个角度。这些多余素材就是后面辅号版本的来源。 |
|---|

3.6.3　一次拍摄 → 四个账号版本的配方

同一批素材，按下面的配方切出四个账号各自的内容。注意：不是同一段视频剪辑四次，而是选不同的素材、配不同的解说、打不同的受众。

| 账号 | 选哪些素材 | 解说角度 | 标题方向 | 时长 |
|---|---|---|---|---|
| 主号（品牌+双线） | 全景 + 成品 + 老板口播 | 公司视角：我们怎么做这件事 | 品牌/服务/案例 | 60~90 秒 |
| 辅号1（工程/经销） | 仓库 + 备货 + 团队 + 产能 | 供货视角：能不能稳定供上 | 库存/发货/代理政策 | 45~70 秒 |
| 辅号2（业主向） | 问题部位 + 避坑口播 + 报价 | 顾客视角：你会踩什么坑 | 避坑/多少钱/怎么选 | 40~60 秒 |
| 辅号3（产品口碑） | 产品特写 + 拆解 + 对比测试 | 测评视角：东西本身好不好 | 实测/对比/真假 | 30~50 秒 |

3.6.4　再切一版给视频号

四个账号的内容做完抖音版之后，再做一遍视频号版本。必须改三处：

| 要改的地方 | 抖音版 | 视频号版 |
|---|---|---|
| 前 3 秒 | 强钩子、快节奏、情绪浓度高 | 可略缓，先从“场景/人”进入，更像聊天 |
| 标题文案 | 短、带话题标签、追求点击 | 长一点、更像一句话说明，便于转发时别人看懂 |
| 封面 | 大字 + 强对比 | 可更生活化，视频号转发到群/朋友圈时封面缩略图很关键 |
| 结尾 | 引导评论/私信 | 引导转发与加微信（视频号私域承接更强） |

| ✓ 八条的账怎么算 2 次拍摄/周 × 每次产出 4 条内容母版 = 8 条母版/周 —— 但这是不够的。 正确算法：1 次工地拍摄可切出 8~12 条抖音版内容，其中 4 条作为当天四账号发布，其余进入素材库备用。 每日发布结构：4 个账号各 1 条抖音版 + 当日其中 4 条做视频号版 = 8 条发布。 一周的拍摄量：2~3 次实地拍摄 + 1 次门店/仓库集中口播拍摄，即可覆盖 56 条周发布量。这就是单人的可行解。 |
|---|

3.7　拍摄规范：不用设备，用方法

3.7.1　设备最低配置

| 设备 | 要求 | 备注 |
|---|---|---|
| 手机 | 近 3 年主流机型，后置主摄拍摄 | 不需要相机。清晰度够用即可 |
| 收音 | 领夹麦（必备） | 这是唯一值得花钱的配件。手机自带麦在工地完全不可用 |
| 补光 | 一个便携LED平板灯 | 室内/仓库/阴天必备，几十元 |
| 稳定 | 手持或几十元的手机支架 | 工地现场不追求运镜，稳定清晰即可 |
| 剪辑 | 剪映（手机版/电脑版） | 免费，模板功能足以支撑批量套剪 |

| ⚠ 单人不该在设备上纠结 建材客户看的是“你是不是真的在做这行”，不是你的画质。一个清晰的、有工地在背后的手持镜头，胜过任何精美摆拍。 唯一例外是收音。工地噪音大，没有领夹麦的素材基本报废，这是唯一必须投入的。 |
|---|

3.7.2　景别与镜头纪律（建材版）

| 景别 | 用途 | 建材现场怎么用 |
|---|---|---|
| 特写 | 展示细节、材质、问题点 | 砖的坯体、铝材断面、打胶收口、五金件 |
| 近景 | 口播、讲解 | 老板/师傅半身，背景要有工地或产品 |
| 中景 | 展示操作过程 | 安装动作、量尺动作、装卸货 |
| 全景 | 展示规模、空间 | 仓库全貌、工地全景、门店展厅 |

· 口播时看镜头，不要看屏幕里的自己（这是最常见的问题，看屏幕会显得心不在焉）

· 每条视频至少 3 个景别切换，否则画面呆板，完播率上不去

· 手持要稳：双手持机、手肘贴身体；走路拍时膝盖微屈减少晃动

· 现场务必先收音测试：录 10 秒回放听一下，有风噪/机器噪音就换位置

· 拍够 B-roll：每个主题额外拍 30 秒环境空镜，剪辑时用来盖口播断层

来源： 景别与拍摄纪律的框架参考 shortvideo-suite 知识库《薛辉手册·第8章 分镜与拍摄》【公开表述】；建材现场的具体用法为 ▸ 本手册推断。

3.8　剪辑规范：模板化，才能批量

单人要日更 8 条，剪辑必须模板化。做法是先做 4 个模板，之后所有视频套模板。

| 模板名 | 结构 | 适用 |
|---|---|---|
| T1 避坑模板 | 钩子字幕（0-3s）→ 老板出镜讲 → 现场画面盖讲 → 结尾行动指令卡 | ③避坑类 |
| T2 拆解模板 | 对比画面开场 → 特写切分 → 参数字幕条 → 结论卡 | ②产品类 |
| T3 案例模板 | 地点卡 → 问题画面 → 施工过程 → 完工对比 → 客户反馈 | ⑤案例类 |
| T4 口播模板 | 纯口播 + 关键词字幕 + 结尾留资引导 | ⑦人设 / ⑥招商类 |

· 统一字体与配色：四个账号用同一套视觉规范，让人一眼看出是一个体系

· 字幕必加：工地噪音大，且大量用户静音刷视频

· 关键数字上大字：价格、年限、尺寸、数量——这些是建材客户的关注点

· 前 3 秒不放片头/LOGO：直接进钩子，品牌片头放在结尾

· 成片控制在 30~70 秒：知识类不超过 70 秒，案例类不超过 90 秒

3.9　标题 · 封面 · 话题 · 发布

3.9.1　标题公式（建材版）

| 公式 | 结构 | 示例 |
|---|---|---|
| 地域 + 问题 + 数字 | 让同城客户觉得“说的就是我这儿” | 杭州老房翻新，这 5 个地方千万别省钱 |
| 对比 + 价格锚点 | 最有冲击力的开头 | 380 一平的门窗和 1800 的，切开看差在哪 |
| 反常识 + 身份 | 打破预期 | 干了 12 年建材，我劝你别买最贵的那款 |
| 避坑 + 后果 | 损失厌恶 | 阳台这样做落地窗，三年后一定出事 |
| 报价 + 拆解 | 最容易被搜索 | 杭州瓷砖多少钱一平？我把成本摊开算 |

· 标题必须带地域词（同城流量的核心标签）

· 控制在 20 字内，超出会被折叠

· 标题是给系统（识别你在讲什么）和用户（决定点不点）同时看的

3.9.2　封面规范

| 要素 | 要求 |
|---|---|
| 尺寸 | 竖版 9:16；视频号分享场景下注意缩略图可读性 |
| 主文案 | 一句话 ≤ 12 字，说出核心利益或冲突 |
| 次文案 | 补充证明，如“实测”“20年经验”“真实报价” |
| 画面 | 自明性：一眼看出是建材/工地/产品，不要用抽象图 |
| 一致性 | 四号统一模板、统一位置，形成体系感 |

来源： 封面“自明性 + 购买理由 + 视觉冲击”三要义参考人人都是产品经理《如何建立小红书运营SOP》woshipm.com/share/6197886.html　【公开表述】；建材化改写与尺寸要求为 ▸ 本手册推断。

3.9.3　话题标签配置（每条约 5~8 个）

| 标签层级 | 作用 | 建材示例 |
|---|---|---|
| 地域标签 | 锁定同城流量 | #杭州 #杭州装修 #杭州门窗 |
| 品类标签 | 让系统识别你做什么 | #断桥铝门窗 #系统窗 #门窗定制 |
| 需求标签 | 承接搜索 | #装修避坑 #装修报价 #老房翻新 |
| 人群标签 | 精准触达 | #自装 #业主装修 #工程建材 |
| 品牌标签 | 四号统一使用，形成矩阵识别 | #杭州XX建材 |

3.9.4　发布时间（同城为主）

| 时段 | 适合内容 | 原因 |
|---|---|---|
| 07:00-08:30 | 知识/避坑类 | 通勤时段，看短内容 |
| 11:30-13:00 | 产品/报价类 | 午休，愿意停留 |
| 17:30-19:00 | 案例/效果类 | 下班路上，看轻松的 |
| 20:00-22:00 | 主推内容放这里 | 全天流量峰值，装修人群活跃 |
| 周末 09:00-11:00 | 案例/工地实拍 | 业主周末集中看装修内容 |

· 四个账号错开 20~30 分钟发布，避免同时段互相挤占

· 同城流量对周末与下班后时段更敏感，优先保证这两个时段的更新

· 固定发布时间有助于形成粉丝预期，但不要为了卡点而推迟发布
