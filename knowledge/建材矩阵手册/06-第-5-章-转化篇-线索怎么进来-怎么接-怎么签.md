第 5 章　转化篇：线索怎么进来、怎么接、怎么签

5.1　先建立一个残酷认知：播放量不产生订单

建材账号最常见的失败模式是：视频有播放、评论有互动、私信没人接、订单一单没有。原因几乎永远是同一个——内容和转化之间缺了一座桥。

这座桥由四段组成：内容里埋钩子 → 主页上给入口 → 咨询时给话术 → 跟进时给节奏。 任何一段断了，前面的流量都白费。

5.2　线索入口：六个位置，一个都不能空

| 入口位置 | 适用 | 具体做法 | 优先级 |
|---|---|---|---|
| 评论区 | B+C | 置顶一条自己写的引导评论；回复时引导到私信 | ★★★★★ |
| 私信 | B+C | 主页开通私信；设置自动回复（留言后自动发说明） | ★★★★★ |
| 主页联系方式 | B为主 | 企业号可挂载联系电话，B端客户更爱直接打电话 | ★★★★★ |
| 主页组件/留资表单 | B+C | 线索组件、表单；让客户留电话与需求 | ★★★★ |
| POI/门店地址 | C为主 | 绑定真实地址，客户可直接导航到店 | ★★★★ |
| 简介行动指令 | B+C | 一句话写清“要合作/要报价，怎么找我” | ★★★★ |
| 视频结尾口播 | B+C | 每条视频结尾都用同一句行动指令，形成条件反射 | ★★★★★ |

5.2.1　每条视频结尾的固定行动指令（四号各一句）

| 账号 | 固定结尾话术 | 为什么这样说 |
|---|---|---|
| 主号 | “在杭州要做这块的，私信发我需求，我按你的情况给方案。” | 地域 + 低门槛 + 明确动作 |
| 辅号1 | “想谈代理或要货的，私信留个联系方式，我把政策和报价表发你。” | B端要的是“政策”和“报价表”，直接给他这两样 |
| 辅号2 | “杭州的业主，把户型图或尺寸发我，我免费帮你算一遍。” | 免费 + 具体动作，转化率最高的一句 |
| 辅号3 | “想知道你家适合哪种，评论区把使用场景告诉我。” | 用评论区降低门槛，适合还没到询价阶段的客户 |

| ✓ 行动指令的三个铁律 每一条视频都必须有。 没有行动指令的视频，等于把客户送到门口又不给门。 四个号用四句固定的话，不要每条都换。 固定话术才能让老客户记住怎么找你。 动作要具体、门槛要低。 “私信发我尺寸”远好于“欢迎咨询”。 |
|---|

5.3　评论区运营：把公共流量变私域

5.3.1　置顶评论：自己写第一条

每条视频发布后，自己第一时间在评论区发一条置顶评论。这条评论的作用是补充视频里没说完的信息，并强化行动指令。

| 视频类型 | 置顶评论文案模板 |
|---|---|
| 避坑类 | “补充一句：[视频里提到的点]，如果你不确定自家是不是这种情况，把照片发我，我帮你看一眼。[城市] 的优先。” |
| 产品拆解类 | “忘了说价格：左边这款 [价格]，右边 [价格]。想要完整参数表的，评论区扣‘参数’，我私发你。” |
| 报价类 | “这是我按 [城市] 市场价整理的，各家会有浮动。想知道你家具体多少，把尺寸发我就行。” |
| 案例类 | “这个客户是 [小区/区域] 的，做的是 [品类]。同小区或同户型的，可以来店里看实物。” |
| 招商类 | “政策细节不方便公开说，想了解的直接私信我，我发你一份完整的代理政策表。” |

5.3.2　评论回复策略

| 评论类型 | 怎么回 | 绝对不要 |
|---|---|---|
| 问价格 | 给区间 + 一个变量：“看你用哪种，一般 [低]–[高] 之间，主要差在 [因素]。把你尺寸发我，我给你算准的。” | 不要只回“私信”；不要不回 |
| 问地址 | 给门店名 + 大致位置 + “导航搜 [名称] 就能到” | 不要含糊，同城客户真的会来 |
| 同行来探 | 礼貌回应，不争论、不攻击 | 不要互撕；不要指名道姓说同行坏话 |
| 差评/质疑 | 公开回应 + 给解决方案：“您说的情况我重视，方便私信告诉我具体是哪一单吗？我核实后给您处理。” | 不要删评（显得心虚）；不要对骂 |
| 闲聊/无关 | 简单回一句或忽略 | 不要投入时间 |

5.4　私信话术库（B端与C端分开）

| ★ 使用说明 下面是话术模板，方括号内替换成你的实际信息。 原则：先给价值，再问需求，最后才谈条件。 一上来就发价格表的，转化率最低。 |
|---|

5.4.1　B端私信话术（装修公司 / 经销商 / 工程商 / 工长）

| 场景 | 话术模板 |
|---|---|
| 首次咨询（对方主动） | “您好，看到您咨询 [产品] 了。方便问一下您这边主要是做 [工程/零售/批发] 吗？我们针对不同类型的合作方，报价政策不太一样，我先按您的情况给您一个准确的。” |
| 发资料（留资后） | “这是我们的产品报价表和政策说明，您先看一下。里面 [第X项] 是可谈的，其他都是统一价。有疑问随时问我，不着急。” |
| 问代理（核心场景） | “代理这块我们现在 [城市/区域] 还有 [几个] 名额。主要看两点：一是您有没有 [门店/工程渠道]，二是起订量能不能接受 [数量]。这两点没问题的话，我可以给您申请 [区域保护/首批支持]。” |
| 报价后无回应（3天） | “上次发的报价您看了吗？如果价格上有压力，可以告诉我您的目标价，我看看能不能在 [某个配置] 上调整一下，先把这个单做下来。” |
| 长期未成交（15天） | “不打扰您，就是提醒一下我们 [本月/本季] 有个 [政策/活动]。另外我们最近到了 [新货]，您做的那个品类刚好有，需要样品的话我寄一份给您。” |
| 寄样品后 | “样品寄出了，单号 [XXX]。收到后建议您 [具体测试方法]，这样能最直观看出区别。有任何问题直接找我。” |

5.4.2　C端私信话术（业主 / 自装）

| 场景 | 话术模板 |
|---|---|
| 首次咨询（问价） | “您好！[产品] 的价格主要看 [两个变量]。您方便说一下 [面积/尺寸/户型] 吗？我按您的实际情况算一个准确的总价，比给区间更靠谱。” |
| 客户发来尺寸/户型图 | “收到，我看了一下。您这个 [户型/尺寸] 有两个点要注意：[问题1]、[问题2]。我按方案A（[简述]）和方案B（[简述]）各算一份，大概 [时间] 给您。” |
| 客户拿同行报价来比 | “这个价格确实低。您方便把报价单发我看看吗？我帮您逐项对一下，看看差在哪几项。不一定要跟我们做，但别在这几项上吃亏。” |
| 客户犹豫（再考虑） | “没问题，这事是要多比较。我把 [资料/实物] 先留给您，您方便的时候可以来店里看看实物，看完再决定。” |
| 邀约到店 | “您方便的话，来店里看实物最直观，地址是 [地址]，您到之前给我发个消息，我给您留着 [样板/样品]。” |
| 长期跟进（30天） | “最近装修进展怎么样了？[对应阶段] 这块如果还没定，我这边 [新到货/有活动]，可以给您留一份。” |

5.4.3　必须避免的四类说法

| 错误说法 | 为什么错 | 改成 |
|---|---|---|
| “最低多少钱？”→“您先说要多少” | 把问题推回去，客户会觉得你不专业 | 主动给区间 + 一个变量 |
| “我们家质量最好” | 无信息量的自夸，客户已听腻 | 给可验证的对比（切开、参数、检测报告） |
| “同行都是坑” | 违反广告法与商业诋毁风险，且显得不自信 | 只讲“怎么辨别”，不点名 |
| “绝对不裂/永不褪色” | 绝对化用语，存在合规风险 | 讲条件：“在 [使用条件] 下，质保 [年限]” |

5.5　线索跟进 SOP：从咨询到签单

建材的成交周期长，线索不跟进等于没有线索。下面这套流程是单人也能执行的最小版本。

| 阶段 | 时间 | 动作 | 话术要点 | 记录什么 |
|---|---|---|---|---|
| T0 抓取 | 咨询当天 | 回复私信/电话，确认真实需求 | 先问需求，不急着报价 | 来源账号、客户类型（B/C）、需求品类 |
| T1 建档 | 当天 | 录入线索表（附录C） | — | 联系方式、需求、预算、时间节点 |
| T2 给方案 | 24 小时内 | 给出报价或方案（B端给政策表） | 给两个方案，让客户做选择而非判断题 | 已发内容、客户反馈 |
| T3 首跟 | T2 后 1 天 | 确认是否收到、有无疑问 | “看一下有没有不清楚的地方” | 客户关注点 |
| T4 二跟 | T3 后 3 天 | 补充案例/实物/样品 | 用同城同小区案例增强说服力 | 是否邀约到店 |
| T5 三跟 | T4 后 7 天 | 邀约到店或寄样 | 给具体时间选项，不给开放问题 | 到店/寄样结果 |
| T6 长跟 | 每 15 天 | 有价值的信息触达（新品、活动、知识） | 不要每次只问“考虑得怎么样” | 状态更新 |
| T7 成交 | — | 签单 + 交付 | — | 成交金额、来源账号 |
| T8 裂变 | 交付后 7 天 | 请客户拍反馈 / 要转介绍 | “能不能帮我们拍一条，我给您 [小回馈]” | 转介绍线索 |

| ✓ T8 为什么必须做 建材客户不复购（第1.2.3节），所以一个成交客户的剩余价值只能从转介绍和内容素材里拿。 请客户拍一条反馈视频，你同时得到两样东西：一条真实度极高的案例素材（用于辅号3 和主号）+ 一个可能带来亲友订单的口碑节点。 这是建材行业投入产出比最高的一个动作，但 90% 的账号不做。 |
|---|
