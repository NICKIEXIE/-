附录 D　客户常见问题应答话术库

本附录收集建材客户最常问的问题及应答思路。注意：涉及价格、质保、承诺的表述，你必须按自己实际情况与合规要求改写。

D.1　C端常见问题

| 客户问 | 应答思路 | 示例话术 |
|---|---|---|
| 你们和 XX 品牌比怎么样？ | 不贬低同行，转为讲“怎么选” | “这两个都是能用的牌子。区别在 [客观差异]。您主要看 [你的关注点]，我建议您按 [方法] 去比，这样不容易吃亏。” |
| 能不能再便宜点？ | 不直接降价，先确认价值锚点 | “价格我可以帮您申请，但我想先确认一件事：您最在意的是 [质量/工期/售后] 哪一项？如果是 [某项]，我建议这一点不要省，其他部分我可以帮您调整配置。” |
| 你们质保多久？ | 讲清条件，不用绝对化用语 | “[产品] 质保 [年限]，覆盖 [范围]。但有一个前提：[使用/施工条件]。这几点我都会写进单子里，避免以后扯皮。” |
| 我先去别家看看 | 支持他去看，留一个钩子 | “应该的，多看看心里有底。我把 [样品/资料] 给您留一份，您看完别家如果拿不准，随时问我，我帮您对一下参数。” |
| 多久能完工？ | 给区间 + 给条件 | “正常 [X] 天。但有两个变量：[变量1]、[变量2]。签单时我会把工期写进合同，超期怎么算也写清楚。” |
| 网上的比你们便宜 | 不比价，比交付 | “线上确实有更便宜的。建材有个特点：便宜的差价通常出在 [辅料/安装/售后]。您可以问一下对方这三项包不包，答案会不一样。” |

D.2　B端常见问题

| 客户问 | 应答思路 | 示例话术 |
|---|---|---|
| 你们能给什么政策？ | 先问他的能力，再谈政策 | “政策分三档，主要看 [渠道/起订量/区域]。您先说说您那边现在主要做哪块？我按您的情况给一档合适的。” |
| 别的厂给我更低的价格 | 比总成本，不比单价 | “单看单价他们确实低。不过您算一下这三项：[运费/账期/售后响应]，加起来可能就不一样了。我把明细列给您看。” |
| 能不能先铺货后付款？ | 给条件，不给空头承诺 | “首次合作我们一般是 [方式]。如果合作满 [时间/量]，可以申请 [账期]。这个我可以帮您往上报，但需要您这边提供 [材料]。” |
| 区域保护怎么算？ | 给明确边界 | “[区域] 内我们只签您一家，条件是 [年度任务]。任务没完成的话，我们第二年可能会再谈，这一点我会提前说清楚。” |
| 我这边量不大能做吗？ | 给入门方案 | “可以。我们有个小批量方案：[内容]。先小量试，跑通了再谈量，这样您风险也小。” |
| 你们发货快不快？ | 给数据和条件 | “常备库存 [数量]，[区域] 内 [时间] 到货。缺货型号我们 [处理方式]。这个我可以写在合作条款里。” |
