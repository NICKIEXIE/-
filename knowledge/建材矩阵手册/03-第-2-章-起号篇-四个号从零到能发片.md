第 2 章　起号篇：四个号从零到能发片

2.1　四账号的开通顺序（不要四个一起开）

一个人同时开四个号，最大的风险不是忙不过来，而是四个号都没养出标签就一起断更。建议按下面的顺序推进，总周期约 3 周。

| 阶段 | 时间 | 动作 | 完成标准 |
|---|---|---|---|
| 第 1 步 | 第 1 天 | 办营业执照相关认证材料、确认经营地址、准备门店/厂房照片 | 材料齐备 |
| 第 2 步 | 第 1~3 天 | 开通企业蓝V主号，完成认证 | 认证通过，后台可进 |
| 第 3 步 | 第 4~7 天 | 主号发第一批 3 条内容，跑通发布流程 | 能独立完成拍摄→剪辑→发布 |
| 第 4 步 | 第 8~14 天 | 开通员工号（辅号1），绑定到企业号下 | 员工号出现在企业号后台 |
| 第 5 步 | 第 15~18 天 | 开通辅号2、辅号3，分别独立认证/绑定 | 四号全部可发 |
| 第 6 步 | 第 19 天起 | 四号进入正式排期（第6.1节节奏表） | 连续 7 天不断更 |

| ★ 为什么主号必须先跑通 因为主号是你唯一会反复改的号。账号简介怎么写、封面用什么风格、老板出镜的状态对不对——这些问题在第一个号上会暴露无数次。 先在主号上把流程跑顺，辅号直接复用已验证的模板，比四个号同时试错快得多。 |
|---|

2.2　企业号（蓝V）：你的主号必须走这条路

主号建议直接认证为企业号（蓝V），而不是用个人号。原因是官方给企业号的能力，恰好就是你做B端获客必需的那些。

2.2.1　企业号给你的、个人号没有的东西

| 能力 | 对你的价值 | 对应第几章 |
|---|---|---|
| 官方认证标识 + 企业名称展示 | B端客户判断你“是不是正经公司”的第一依据 | 第5章信任建立 |
| 主页可挂载联系方式/线索组件 | 把流量变成线索的关键入口，个人号做不了 | 第2.4节 |
| 可创建员工号、形成矩阵 | 你四个号结构的官方合规载体 | 第4章 |
| POI（门店/地址）挂载与经营工具 | 同城流量的核心抓手 | 第2.4节 |
| 后台经营数据与线索管理 | 才算得出“哪条视频带来了询盘” | 第6.3节 |
| 直播经营工具 | 后续做B端招商/答疑直播的基础 | 第7章 |

来源： 抖音企业号官方介绍 m.oceanengine.com/resource/douyin/qiyehao；抖音企业认证 renzheng.douyin.com/site/open_platform　【官方】

2.2.2　认证要准备什么（清单）

☐  营业执照（经营范围需覆盖你实际售卖的产品）

☐  企业对公账户或法人身份信息（按认证页面要求）

☐  门店/厂房的门头照片、内部实景照片（认证审核与后续装修都要用）

☐  经营地址准确到门牌号（POI 定位要用，填错会导致同城流量错投到隔壁城市）

☐  行业资质：涉及建材的检测报告、品牌授权书、代理证书（有就备好，B端谈判时是硬通货）

☐  企业号名称：建议格式为「品牌/店名 + 城市 + 主营品类」，例如「XX门窗·杭州」或「杭州XX建材」

☐  联系方式的多个渠道（电话、微信、企业微信），后续要在主页和组件里配置

| ★ 账号名称的一个关键取舍 不要用纯品牌名（如“XX建材有限公司”）。同城客户搜索时不会搜你的品牌，他搜的是“杭州断桥铝门窗”“杭州瓷砖批发”。 建议结构：地域 + 主营品类 + 品牌/人名。例如“杭州老张做门窗”。 带人名的好处是：B端客户谈代理时记得住你这个人，C端业主觉得“是个真人在做事”。 |
|---|

2.3　员工号与职人号：辅号的合规载体

你的三个辅号，不建议注册成毫无关联的个人号，而是走企业员工号 / 职人号体系。这是平台官方提供的、用于形成经营矩阵的账号类型。

2.3.1　官方矩阵账号的三类角色

| 类型 | 是什么 | 谁来用 | 在你这里的用途 |
|---|---|---|---|
| 品牌号 （企业号） | 公司官方主体账号 | 公司 | 主号：品牌背书 + 双线内容 |
| 员工号 | 企业申请创建后分配给员工使用的账号，可授权员工在短视频/直播场景使用企业号营销工具 | 公司员工、门店店员、设计师、安装师傅 | 辅号的主要形式：安装师傅号、设计师号 |
| 合作号 | 与合作方（经销商/服务商）绑定的账号 | 经销商、工程商、合作门店 | 跨区域B端的关键：各地经销商各自开号，你做内容赋能 |

来源： 抖音开放平台《小程序经营矩阵账号介绍》developer.open-douyin.com；抖音生活服务《职人产品手册》lifexue.com/news/detail/134271　【官方】

2.3.2　员工号的三个实际好处

· 内容天然差异化：安装师傅讲施工、设计师讲搭配、仓库讲库存，同一个人设讲不同的事，不会互相抢流量（解决第4章的核心难题）

· 信任感更强：C端业主看到“穿工服、在工地、手上有活”的人，信任度高于老板在办公室口播

· B端更专业：经销商看到你有成体系的员工号和施工团队，会判断你“不是小作坊”

| ★ 如果暂时没有员工怎么办 你说团队暂时是一个人。那“员工号”可以先用老板本人的第二身份来承载，例如主号是“杭州老张做门窗”（老板视角），辅号是“老张讲安装”（技术/师傅视角）。 关键不是谁出境，而是人设不同。 只要人设和内容方向不同，即使是同一个人拍，两个账号也不会互相被判重复。 等你招到第一个人（最可能是安装师傅或门店店员），第一个动作就是把辅号的出镜人换过去，并按第8章的分工表交接。 |
|---|

2.4　账号装修清单：让人一眼知道你是干什么的

建材类账号的装修，目标只有一个：客户点进主页后 5 秒内，知道你在哪个城市、卖什么、能不能信、怎么联系你。 这四件事必须在主页上全部解决。

2.4.1　逐项装修清单（四号通用）

| 位置 | 要求 | 建材行业的正例 / 反例 |
|---|---|---|
| 头像 | 真人 + 工服/门店背景，或清晰的品牌LOGO。不用网络图片 | 正：老板在门店门口的半身照；反：随手找的风景图 |
| 账号名 | 地域 + 品类 + 人名/品牌 | 正：杭州老张做门窗；反：追梦人888 |
| 简介第一行 | 一句话说清你是做什么的 | 正：杭州本地门窗厂，自有安装队，工装家装都做 |
| 简介第二行 | 说清你的独特优势（交付/价格/服务） | 正：断桥铝系统窗，工厂直供，安装质保5年 |
| 简介第三行 | 明确行动指令 | 正：同城免费上门量尺｜私信报面积即可 |
| 背景图 | 门店/厂房/展厅实景，可压一行大字 | 正：车间实拍 + “自有工厂 直供无中间商” |
| POI 定位 | 必须绑定真实经营地址 | 绑定后同城流量才准；未绑定则地域标签靠猜 |
| 联系方式 | 企业号可挂载联系电话/组件 | B端客户倾向于直接打电话，比私信转化率高 |
| 主页封面统一 | 统一封面风格，让人一眼看出内容体系 | 正：白底大字 + 统一配色；反：每条风格都不同 |
| 置顶视频 | 置顶 3 条：一条讲你是谁、一条最强案例、一条最实用的知识 | 新客户会先看置顶，这是你的“线上名片” |
| 合集 | 按品类/问题建 3~5 个合集 | 让搜索进来的客户一次看完，提升停留 |

2.4.2　四个号的装修差异表

装修风格要能一眼区分，但因为都是同一家公司，配色和字体必须统一，让人看出是“一个体系里的不同人”。

| 账号 | 简介定位写法（示例） | 背景图 | 置顶三条 |
|---|---|---|---|
| 主号 品牌+双线 | 杭州XX建材｜门窗·瓷砖·辅材一站式｜工装家装均可｜同城上门 | 门店/展厅全景 | ①老板自我介绍 ②最强工程案例 ③产品工艺揭秘 |
| 辅号1 工程/经销 | 杭州XX建材·工程渠道｜诚招区域代理｜工厂直供｜拿样即发 | 仓库/库存实拍 | ①工厂产能实拍 ②代理政策 ③发货现场 |
| 辅号2 业主向 | 杭州装修选材避坑｜老张只讲真话｜同城免费量尺报价 | 工地/样板间 | ①避坑知识 ②业主实拍反馈 ③报价拆解 |
| 辅号3 产品/口碑 | 杭州XX建材·产品实测｜每个材料拆开给你看｜不踩坑 | 产品特写墙 | ①材料对比实测 ②真假鉴别 ③客户验收现场 |

2.5　开号第一天就要做的五件事（不要养号七天）

关于“新号要先养七天”，本手册的立场是：对企业号与员工号，没有证据支持这一说法，而它带来的机会成本很高。 你的行业获客周期本来就长，浪费七天是纯损失。

当然，这不意味着你可以乱来。你要做的是下面五件事：

☐  完善资料：头像、名称、简介、背景图、POI、联系方式全部填完整（这是平台判断账号质量的真实依据）

☐  发布第一条内容：建议就是“我是谁 + 我在哪 + 我做什么 + 我能帮你解决什么”，60 秒内讲完

☐  建立合集：至少建一个合集，把后续内容归进去（合集对搜索和复访都有帮助）

☐  绑定企业后台：确认能看到线索数据，否则第6章的数据看板无从建立

☐  测试发布链路：完整走一遍“拍摄→剪辑→加标题→加话题→选封面→发布”，确认每一步都顺畅，避免后面批量发布时卡壳

2.6　常见起号问题速查

| 问题 | 本手册的判断 |
|---|---|
| 要不要做个人号而不是企业号？ | 主号必须企业号（线索组件、员工号、POI 都依赖它）。辅号可用员工号，不必另开个人号 |
| 营业执照范围不够怎么办？ | 先按现有范围认证，主页与内容按实际经营描述；范围问题更多影响后续开通某些经营工具，不影响发内容 |
| 一个手机能挂几个号？ | 官方产品支持多账号切换，但四个号建议分布在不同设备，避免同设备频繁切换带来的账号关联判定 |
| 网络要不要分开？ | 四个号都在你自己的门店/办公室，用正常办公网络即可。不需要也不应该做IP伪装（见第1.5节） |
| 账号名能不能改？ | 能，但越早定越好。名称频繁变更会影响老客户识别与搜索 |
| 先做抖音还是先做视频号？ | 你说两个都发。建议抖音为主战场（同城流量池更大），视频号作为信任与私域承接的第二阵地 |
