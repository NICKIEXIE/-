第 7 章　增长篇：自然流怎么放大

7.1　先明确：你不需要投流，但需要知道什么时候该投

你说纯自然流。本手册尊重这个选择——对建材同城生意来说，自然流完全够用，因为你的客户基数本来就不需要百万曝光。

但有一个前提条件：你必须先把自然流的转化链路跑通。 在链路没跑通之前投流，等于花钱放大一个漏水的桶。

| ★ 什么信号出现时，才值得考虑小额投流 信号一：四号都稳定有线索，且你忙不过来（承接能力成为瓶颈）。 信号二：某一条视频自然流表现突出，且带来了成色很好的线索——这条值得加热。 信号三：你有本地推/线索类投放的小额预算（几百元级），且能接受不保证回报。 三个信号都没出现，就不要投。 自然流先做到第6章的节奏，再谈放大。 |
|---|

7.2　自然流的六个放大杠杆（不花钱）

| 杠杆 | 具体做法 | 预期效果 |
|---|---|---|
| 搜索优化 | 标题带地域词+品类词+决策问题；把高频搜索词做成系列内容 | 建材最有效的一条：承接主动搜索的精准客户 |
| 合集运营 | 四号各建 3~5 个合集（按品类/问题），把同类内容归入 | 提升复访与停留，搜索进来的人一次看完 |
| 置顶策略 | 四号各置顶 3 条：自我介绍、最强案例、最实用知识 | 新客户第一落点，等于线上名片 |
| 同城地标内容 | 标题与画面带小区名、建材市场名、区域名 | 强化同城标签，让本地客户觉得“就是这儿” |
| 问答与评论区 | 在小红书/知乎/本地社群同步回答装修问题，留品牌词 | 跨平台引流，且对搜索有长期价值 |
| 经销商协同 | 让合作经销商/工程商各自开号，你提供素材模板 | B端放大最快的方式（见7.3节） |

7.3　B端放大：把你的经销商变成矩阵节点

这是建材行业最独特、也最被低估的放大方式。行业里有企业推动约 8000 家经销商开号，由总部给本地化运营支持——这就是你未来最值得走的路。

7.3.1　分三步走

| 步骤 | 动作 | 你提供什么 | 经销商做什么 |
|---|---|---|---|
| 第一步：单点验证 | 找 2~3 个关系最好的经销商试点开号 | 素材模板、脚本、剪辑规范、发布节奏表 | 用自己的账号发本地内容 |
| 第二步：素材供给 | 你拍好的工厂/产品/案例素材，开放给经销商使用 | 统一的素材库 + 本地化改写指引 | 换成自己的门店、自己的口播 |
| 第三步：形成区域网 | 每个区域一个号，形成真正的区域矩阵 | 品牌词统一、货源保障、区域保护政策 | 各自承接本地B端与C端客户 |

| ✓ 为什么经销商愿意做 因为他们缺的正是你不缺的：产品素材、脚本、方法。 而你不缺的正是他们缺的：更关键的是，他们缺本地客户，而你有货源和品牌。 谈的时候不要谈“帮我发视频”，要谈“我帮你获客，素材和话术我都给你”。 这个顺序决定了他们做不做。 |
|---|

7.4　可选：小额投流的正确姿势（仅在有预算时）

本节仅在你决定投入预算时参考。不做投流不影响本手册其余部分的执行。

| 项目 | 建议做法 |
|---|---|
| 投什么 | 只投已经自然流验证过的视频，不要投新视频 |
| 投给谁 | 同城定向（你的城市 + 周边区县）；B端内容可放宽到省内 |
| 投多少 | 单条从最小额度起测，单条不超过你能承受的一次性损失 |
| 看什么 | 不看完播率，看线索成本（投放花费 ÷ 带来的有效咨询数） |
| 什么时候停 | 线索成本超过单个客户的预期利润时立即停 |
| 最忌讳 | 同时投多条——无法归因，不知道哪条有效 |
